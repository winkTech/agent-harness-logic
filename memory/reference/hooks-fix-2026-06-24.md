# 三大闸门修复记录 (2026-06-24)

## 根因（纠正后）
**不是 hooks 不触发，不是 exit code 2 被忽略，而是路径格式问题。**

`settings.local.json` 中所有 hook 命令使用 `"$HOME/.claude/..."` 格式。Harness 在 PreToolUse/PostToolUse 事件中**可能不展开 `$HOME`**，导致脚本路径解析失败，hook 静默 exit(0)。

## 修复方案

### `~/.claude/settings.json` — 新增三大闸门（绝对路径）
使用 `[HOME_DIR]/...` 绝对路径：
```json
{
  "hooks": {
    "PreToolUse": [
      {"matcher": "Write", "hooks": [{"type":"command",
        "command": "node [CLAUDE_HOME]/engine/scripts/hooks/local-runner.cjs hdl-gate.cjs"}]},
      {"matcher": "Bash", "hooks": [
        {"type":"command", "command": "node [CLAUDE_HOME]/engine/scripts/hooks/verification-gate.cjs"},
        {"type":"command", "command": "node [CLAUDE_HOME]/engine/scripts/gates/commit-gate.cjs"}
      ]}
    ],
    "PostToolUse": [
      {"matcher": "Edit|Write|MultiEdit", "hooks": [{"type":"command",
        "command": "node [CLAUDE_HOME]/engine/scripts/hooks/verification-gate.cjs"}]}
    ]
  }
}
```

### `~/.claude/settings.local.json` — 替换 50 处 `$HOME` 为绝对路径 + 移除重复钩子
- 全部 `$HOME` → `[HOME_DIR]`
- 移除了迁移到 settings.json 的重复钩子（hdl-gate Pre/Post、verification-gate、commit-gate）
- 保留非 Gate 钩子（SessionStart、Stop、PreToolUse(*) 认知层等）

### `ecc-runner.cjs:66` — 修复 ReferenceError
`file.stderr` → 删除（遗留的未定义变量引用）

## 各闸门实测结果

| 闸门 | 用例 | 结果 |
|:-----|:------|:-----|
| Write Gate PreToolUse | `01_src/00_hdl/mod/mod.sv` 无 TB | ✅ 阻断，显示 Testbench-First |
| Write Gate PostToolUse | `*.sv` 含 `initial` | ✅ exit 2 + 自动修复 ri_/ro_ |
| Bash Gate PostToolUse | 编辑文件后 | ✅ verify-gate.json 创建 |
| Bash Gate PreToolUse | 编辑后非验证命令 | ✅ 阻断，显示提示 |
| ecc-runner | 调用 | ✅ ReferenceError 修复 |

## 未解决的问题
- SessionStart 的 `"$HOME"` 格式能工作（说明 SessionStart 做了 shell 展开），但 PreToolUse/PostToolUse 可能不展开。确切区别待确认。
- `settings.local.json` 仍保留 hdl-gate PreToolUse 作为备份（与 settings.json 重复，重启后双触发，不影响功能）
