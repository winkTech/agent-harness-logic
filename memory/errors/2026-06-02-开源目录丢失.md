# 错误记录: 开源目录丢失

## 错误描述
创建的开源目录在操作后消失

## 错误时间
2026-06-02 10-16

## 解决方案
检查目录创建是否成功，使用绝对路径

## 根本原因
相对路径引用问题：工作目录随上下文切换（如 skill/agent 加载），导致目录创建在预期之外的位置

## 经验教训
Agent 环境下工作目录不可靠，所有文件/目录操作必须使用绝对路径

## 避免规则
所有 mkdir/create/write 操作使用绝对路径，涉及新目录创建需先确认父路径存在
