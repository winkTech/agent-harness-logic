# 错误记录: PDF提取限制

## 错误描述
markitdown 无法提取某些 PDF 文本

## 错误时间
2026-06-02 09-26

## 解决方案
使用 rag-skill 的 markitdown-convert.py

## 根本原因
markitdown 库对某些编码/加密/扫描版 PDF 支持不完整，部分中文 PDF 因字体嵌入方式不同而提取失败

## 经验教训
PDF 文本提取不能完全依赖单一工具，需准备备选方案和手动确认机制

## 避免规则
批量提取前先抽样测试 PDF 文件兼容性，确认工具支持后再全量处理
