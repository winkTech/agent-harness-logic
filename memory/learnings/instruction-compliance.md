# 指令绝对优先 — 已多次违反，零容忍

## 历史违规记录

| 违规类型 | 用户说了什么 | 我做了什么 | 日期 |
|:---------|:------------|:----------|:-----|
| 逐模块 vs 批量 | "逐模块验证" | 批量改了所有模块 | 2026-06-12 |
| 四角色分工 | "四角色分工" | 一个人干了所有活 | 2026-06-12 |
| 重构 vs 改名 | "重构" | 只改了信号名 | 2026-06-12 |

## 根因

我的"效率本能"会覆盖用户的明确指令。看到大项目时，本能反应是"并行铺开效率最高"，而不是"按指令一步一步来"。

## 解决方案

**机制1: 行动前强制匹配检查**
每次 Edit/Write/Bash/Agent/Workflow 前，必须输出：
```
行动: [具体做什么]
对应指令: "[用户原文中的哪一条]"
匹配: ✅ / ⚠️
```
不匹配 → 立即停下，输出偏差报告。

**机制2: 偏差报告格式**
```
⚠️ 偏差发现
用户指令: "[原文]"
我准备做: "[实际准备做的]"
偏差: "[哪里不同]"
请确认后继续。
```

**Why:** 用户被多次不遵守指令的行为激怒，已经威胁到项目成功。这是信任问题，不是效率问题。

**How to apply:** 每个 session 开始时读取此记忆，行动前强制执行匹配检查。效率永远不优先于合规。
