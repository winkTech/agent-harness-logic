# 知识检索优先级规则

**核心原则：知识检索必须优先在本地知识库匹配，再进行全网检索。**

**Why:** 本地知识库包含已验证的领域知识（参考书籍标注、既往项目经验），且不依赖外部网络。全网搜索作为补充手段，不应替代本地知识检索。

**How to apply:**
1. 先用 Grep/Glob 搜索 knowledge/ 目录下的 .md 和 .pdf 文件
2. 搜索关键词要覆盖中英文（如 `rrc|根升余弦|raised.cosine|成形滤波|pulse.shaping`）
3. 检查 `*-source.md` 文件（PDF 标注转写），这些是已建立的知识条目
4. 本地知识库无匹配时再使用 WebSearch
5. 同一任务多次检索时仍优先检查本地库

**检查清单（每次外部检索前自查）：**
- [ ] 是否已用 Glob 搜过匹配文件名？
- [ ] 是否已用 Grep 搜过 knowledge/ 下所有 .md？
- [ ] 是否已用 Grep 搜过 knowledge/ 下 PDF 的 source 标注？
- [ ] source 文件中是否有相关章节可查？
