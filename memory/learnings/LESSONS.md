## 最佳实践

### 记录原则

| 原则 | 说明 |
|------|------|
| **及时性** | 完成任务后立即记录 |
| **完整性** | 记录完整的信息 |
| **准确性** | 确保信息准确 |
| **关联性** | 建立记忆关联 |

### 分类原则

| 类型 | 内容 | 格式 |
|------|------|------|
| **work/** | 工作进度、决策 | YYYY-MM-DD-主题.md |
| **errors/** | 错误详情、解决方案 | YYYY-MM-DD-问题.md |
| **learnings/** | 经验教训、最佳实践 | 主题.md |

### 使用原则

| 原则 | 说明 |
|------|------|
| **主动检索** | 工作前主动检索相关记忆 |
| **引用记忆** | 在决策中引用相关记忆 |
| **更新记忆** | 发现新信息时更新记忆 |
| **清理过期** | 定期清理过期记忆 |

## 开源项目经验

### 1. 评估阶段

| 步骤 | 说明 |
|------|------|
| **完整性检查** | 对比原始目录，识别缺失内容 |
| **优先级分类** | P0（必须）→ P1（应该）→ P2（可以） |
| **风险评估** | 识别安全风险和功能缺失 |

### 2. 实施阶段

| 步骤 | 说明 |
|------|------|
| **分阶段实施** | 先 P0，再 P1，最后 P2 |
| **验证检查** | 每步完成后验证 |
| **记录过程** | 记录每步操作 |

### 3. 安全考虑

| 考虑 | 说明 |
|------|------|
| **敏感信息** | API Token、个人路径必须脱敏 — [[desensitization-rule]] |
| **个人数据** | 记忆、知识库选择性开源 |
| **许可证** | 选择合适的开源许可证 |
