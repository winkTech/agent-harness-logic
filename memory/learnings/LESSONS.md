## 最佳实践

### 记录原则

| 原则 | 说明 |
|------|------|
| **及时性** | 完成任务后立即记录 |
| **完整性** | 记录完整的信息 |
| **准确性** | 确保信息准确 |
| **关联性** | 建立记忆关联 |

### 分类原则

| 类型 | 内容 | 格式 |
|------|------|------|
| **work/** | 工作进度、决策 | YYYY-MM-DD-主题.md |
| **errors/** | 错误详情、解决方案 | YYYY-MM-DD-问题.md |
| **learnings/** | 经验教训、最佳实践 | 主题.md |

### 使用原则

| 原则 | 说明 |
|------|------|
| **主动检索** | 工作前主动检索相关记忆 |
| **引用记忆** | 在决策中引用相关记忆 |
| **更新记忆** | 发现新信息时更新记忆 |
| **清理过期** | 定期清理过期记忆 |

## 错误处理流程

```
发现问题 → 自动记录 → 深入分析 → 提取规则 → 建立关联
    ↓
  errors/     ↓
  自动创建    ↓
              ↓
        learnings/
        提取教训
              ↓
        rules/
        建立规则
```

## 成功复用流程

```
完成任务 → 自动识别 → 模式提取 → 模板化 → 文档化
    ↓
  work/      ↓
  自动识别    ↓
              ↓
        patterns/
        模式提取
              ↓
        templates/
        模板化
```
