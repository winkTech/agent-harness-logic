# 软件安装路径规则

## 规则

安装任何软件时，**默认安装到 D 盘**（或其他非系统盘），**不得装到 C 盘**，除非用户明确说 "装到 C 盘"。

## 原因

- C 盘是系统盘，空间宝贵
- 软件占用空间大，容易挤爆系统盘
- 重装系统时 C 盘软件全部丢失

## 操作流程

```
1. 安装前确认 D 盘（或其他非 C 盘）有足够空间
   - 检查磁盘剩余容量
   - 确认安装目录可写

2. 安装时指定路径
   - 自定义安装选项中选择 D:\Program Files\<AppName>
   - 或 D:\<AppName>
   - 避免 Program Files (x86) 等长路径

3. 如果软件强制装 C 盘
   - 通知用户该情况
   - 让用户决定是否继续

4. 例外（需明确授权）
   - 用户说 "装到 C 盘"
   - 系统工具/驱动必须驻留系统盘
```

## 如何应用

每次执行软件安装任务前，先确认目标路径不是 C 盘。如果安装程序没有自定义路径选项，使用 mklink /J 链接到 D 盘。
