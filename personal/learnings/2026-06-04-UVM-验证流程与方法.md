# UVM 验证框架 — OFDM TX 实战

在 Vivado xsim 2023.1 + UVM 1.2 上搭建了完整的 OFDM TX 验证平台，覆盖接口定义、组件树、TLM 数据流、编译流程与测试用例编写。

## 核心理念

**Sequence 分离驱动与测试逻辑**：测试只描述"做什么"（激励组合），driver 只负责"怎么做"（时序驱动），scoreboard 独立验证正确性。三权分立让 RTL 改一版只需改黄金向量，添加测试用例只需写新 sequence。

## 组件树

```
tb_top → ofdm_base_test → ofdm_env → ofdm_agent
  ├── axi_stream_driver #(16)        ← 驱动 s_axis
  ├── axi_stream_monitor #(16)       ← 监听 s_axis
  ├── axi_stream_output_monitor #(32)← 监听 m_axis
  └── ofdm_scoreboard                ← 比对 vs 黄金向量
```

**Why:** 输入输出分别独立 monitor，输出用 passive 模式（不驱动 tready）。scoreboard 同时接收 in/out 两路 TLM port，实现完全自动化比对。

## 四要素

| 要素 | 实现 | 注意点 |
|:----|:-----|:-------|
| 虚接口 | `axi_stream_if #(WIDTH)` + `clocking block` | 类型参数必须精确匹配 `#(16) ≠ #(32)` |
| config_db 传递 | `set(null,...)` 全局 / `set(this,...)` 局域 | `run_test()` 前用 null 前缀 |
| Sequence 驱动 | `seq.start(env.agent.sqr)` | `uvm_do_on` 只能在 `uvm_sequence::body()` 中使用 |
| Scoreboard 比对 | Golden 文件逐行对比 | MATLAB `uint32()` 打包 hex，report_phase 统计 ERROR 数 |

## 对 FPGA 验证的裁剪

1. **`force` 替代 DPI** — 复位/错误注入不依赖 DPI，避免仿真器 UVM 库兼容问题
2. **`clocking block` 精确相位** — 驱动 +1ps / 采样 -1ps，避免竞争
3. **黄金向量文件替代参考模型** — 降低开发量，MATLAB 生成 packed hex
4. **参数化 `#(WIDTH)`** — 一套 driver/monitor 适配不同位宽

## 编译流程

```tcl
xvlog --define UVM_NO_DPI ... xlnx_uvm_package.sv   # 1: UVM 库 (必须 4 个 NO-DPI 宏)
xvlog --sv reset_if.sv axi_stream_if.sv              # 2: 接口
xvlog --sv ofdm_uvm_pkg.sv                           # 3: UVM 组件
xvlog --sv .../*.sv                                   # 4: RTL 设计
xvlog --sv tb_ofdm_uvm_top.sv                        # 5: 顶层
xelab tb_ofdm_uvm_top -timescale 1ns/1ps             # 6: 链接
xsim tb_ofdm_uvm_top --runall                        # 7: 运行
```

ModelSim 同理，`vlog +define+UVM_NO_DPI` + `vsim -sv_lib uvm`。

## 踩坑

1. **`run_test()` Fatal** — UVM 要求 0 时刻调用，不能有 `#100`
2. **config_db 类型不匹配** — 虚接口参数化类型 `#(6) ≠ #(16)` 无声失败
3. **复位极性反** — `rst_n` 低有效转高有效必须取反
4. **State 死锁** — AXI-Stream `tready` 条件遗漏 IDLE 状态导致无法退出
5. **Golden 全 0 匹配** — 负数的 packed hex vs signed decimal 格式差异，用 `uint32()` 强制打包
6. **xsim 极慢** — SVG queue 实现的 FIFO 在 xsim 中效率极低，后续需换 Xilinx FFT IP

**How to apply:** 新模块接入 UVM 时：① 定义 AXI-Stream 虚接口参数化位宽 ② 写 sequence 描述激励 ③ MATLAB 生成黄金向量 ④ 跑 xsim 全自动比对。改 RTL 只需更新 golden 文件，测试框架不动。
