# 算术逻辑部件设计

> 基于《算术逻辑部件设计_蒋小龙》整理
> 模板代码位于 `templates/alu/` 目录

---

## 一、加法器设计

### 1.1 一位全加器

- **功能**：实现一位全加运算
- **公式**：D = A @ B @ Ci，Co = A & B # (A # B) & Ci
- **应用**：保留进位加法器，高速处理部件的基本元件

### 1.2 4位串行进位加法器

- **功能**：四个一位全加器级连
- **缺点**：高位运算必须等低位进位，延迟大
- **应用**：低速场合

## 二、超前进位链设计

### 2.1 进位生成函数和传输函数

- **进位生成函数G**：Gn = An & Bn
- **进位传输函数P**：Pn = An # Bn
- **进位公式**：Cn+1 = Gn # Pn & Cn

### 2.2 4位超前进位链

- **功能**：消除进位传播，实现高速进位
- **延迟**：两级门延迟
- **模板文件**：`templates/alu/carry_lookahead_4bit.v`

### 2.3 16位超前进位链

- **功能**：用4个4位超前进位链单元串接
- **结构**：两级超前进位链树
- **延迟**：六级门延迟

### 2.4 更多位超前进位链

- **64位**：可用4位或8位单元构成
- **设计考虑**：连线延迟、逻辑门扇入扇出、逻辑门延迟

## 三、算术运算设计

### 3.1 加法运算

- **公式**：D = A + B + Ci

### 3.2 减法运算

- **公式**：D = A - B - Ci = A + (~B) + (~Ci)
- **关键**：减法可转换为加法（补码运算）

### 3.3 可控加减法运算

- **控制信号**：as（0加法，1减法）
- **公式**：D = A + (asv @ B) + (as @ Ci)
- **进位生成**：G = A & (asv @ B)
- **进位传输**：P = A # (asv @ B)

---

## 四、逻辑操作设计

### 4.1 逻辑操作类型

- **与操作**：D = A & B = G
- **或操作**：D = A | B = P
- **异或操作**：D = A ^ B = G @ P

### 4.2 控制信号

- **lc**：2位控制信号（00与，01或，1X异或）

---

## 五、标识位设计

### 5.1 零标志（ZF）

- **设置条件**：结果为零时置1

### 5.2 进位标志（CF）

- **加法**：直接跟踪原进位
- **减法**：将原进位取反

### 5.3 符号标志（SF）

- **设置条件**：跟踪结果的最高位

### 5.4 溢出标志（OF）

- **公式**：OV = Cmsb+1 @ Cmsb
- **加法溢出**：二操作数符号相同，结果符号相反
- **减法溢出**：减数、结果符号相同，被减数符号相反
