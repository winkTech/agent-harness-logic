## 时序安全规则(优先级最高)
- 同步复位：必须使用高电平同步复位
- 输入信号寄存：所有输入信号必须寄存（使用ri_前缀）
- 输出信号处理：组合逻辑输出禁止，必须通过寄存器输出
- 跨时钟域处理：自动插入同步器链
- 数据-使能对：强制配对检测，格式为i_xx_data/i_xx_dvalid
- 模块输入输出时钟与复位：强制配对检测，格式为i_clk_xx/i_rst_xx
- 所有异步输入需要双寄存器同步(两级FF级联)

## 命名规则体系
### 信号前缀规则
- 输入信号：i_前缀（如i_clk）
- 输出信号：o_前缀（如o_data）
- 寄存器：r_前缀（如r_counter）
- 连线：w_前缀（如w_enable）
- 寄存输入：ri_前缀（如ri_data_valid）
- 寄存输出：ro_前缀（如ro_result）
- 参数/状态：P_前缀（如P_ST_IDLE）
- 数组：_array结尾（如w_data_array）
- 跨时钟域：_cdc开头（如xx_cdc）
### 例外规则
- AXI等标准接口信号不受前缀规则约束，保持协议原生命名

## LUT/映射模块编码规则
涉及星座映射、查找表、比特-符号编码的模块必须：
- **比特流追踪注释**：在映射代码附近写清完整的比特流追踪路径：
  ```verilog
  // w_sym_index[5:0] = {buf[0],buf[1],buf[2],buf[3],buf[4],buf[5]}
  //                  = {b0,b1,b2,b3,b4,b5} (b0=first bit=MSB for bi2de)
  // deSig = b0*32 + b1*16 + b2*8 + b3*4 + b4*2 + b5
  // I = sign(b5) × mag({b3,b1}) → see phase-reflection.md §5.2
  ```
- **模型优先**：MATLAB 模型是映射的唯一参考，RTL 必须精确复现 `bi2de('left-msb') + cnstPattern`
- **全索引覆盖**：使用 `unique case` 确保所有可能索引值均有显式映射，default 仅作防误保护

## 关键设计规范
### 输入输出处理
- 输入寄存：所有输入信号必须打一拍寄存，降低关键路径延时
- 输出驱动：通过ro_寄存器+assign语句驱动最终输出
- AXI等标准接口信号不受该规则约束
### 复位规范
- 同步复位
- 高电平有效复位
### 状态机设计
- 必须包含default分支
- 当前计算逻辑到下个时钟周期才可使用
- 状态机通常情况下采用三段式进行设计
- 使用localparam定义状态
- 状态转换逻辑清晰
### 数组处理
- 复位时采用{default:'d0}语法初始化
- 支持数组整体赋值
- 禁止使用initial语句初始化
### 流水线设计
- 寄存器隔离每级计算
- valid信号严格同步传递
- 复位清除所有流水状态
- 计算位宽自动扩展

## 代码结构规范
### 代码结构顺序
- 代码接收循序如下：  
1. 模块声明和I/O定义
2. 输入信号寄存（ri_）
3. 输出信号寄存（ro_）和assign
4. 参数/状态定义（P_）
5. 例化模块
6. 状态机实现
7. 组合逻辑
8. 时序逻辑
9. 数组赋值（放最后）
### 注释规范
- 模块头部注释说明功能
- 注释需要对齐
- 加减乘除等算法和逻辑处理需要注释其相关公式
- 尽量每个always、generate、task、function都有完整简练的注释
- 顶端写出代码主要逻辑、用途、关键状态跳转等
- 注释采用英文撰写

## 代码对齐规范
### 信号声明对齐
- 位宽对齐：[X:0]统一缩进至相同列
- 信号对齐：变量名起始位置对齐
- 分号对齐：所有分号垂直对齐
- 注释对齐：所有//垂直对齐，注释文本对齐
### 连续赋值对齐
- assign关键字左对齐
- 左值对齐：输出信号名起始位置对齐
- 等号对齐：所有=垂直对齐
- 右值对齐：表达式起始位置对齐
- 分号对齐：所有分号垂直对齐
- 注释对齐：所有//垂直对齐
### 特殊场景处理
- 信号名超长（超过20字符）时：
    • 位宽对齐可适当放宽
    • 注释可单独成行
    • 必须保持等号、分号、注释符号垂直对齐
- 推荐：超长信号名控制在32字符内
