## §1 LUT/映射模块编码规则

涉及星座映射、查找表、比特-符号编码的模块必须：

- **比特流追踪注释**：在映射代码附近写清完整的比特流追踪路径：
  ```verilog
  // w_sym_index[5:0] = {buf[0],buf[1],buf[2],buf[3],buf[4],buf[5]}
  //                  = {b0,b1,b2,b3,b4,b5} (b0=first bit=MSB for bi2de)
  // deSig = b0*32 + b1*16 + b2*8 + b3*4 + b4*2 + b5
  // I = sign(b5) × mag({b3,b1})   // 具体符号-幅度关系以项目 Golden Model 为准
  ```
- **模型优先**：MATLAB 模型是映射的唯一参考，RTL 必须精确复现 `bi2de('left-msb') + cnstPattern`
- **全索引覆盖**：使用 `unique case` 确保所有可能索引值均有显式映射，default 仅作防误保护

## §2 关键设计规范

### 数组处理
- 复位时采用 `{default:'d0}` 语法初始化
- 支持数组整体赋值
- 禁止使用 `initial` 语句初始化

### 流水线设计
- 寄存器隔离每级计算
- valid 信号严格同步传递
- 复位清除所有流水状态
- 计算位宽自动扩展

## §3 代码结构规范

### 代码顺序
```
1. 模块声明和 I/O 定义
2. 输入信号寄存（ri_）
3. 输出信号寄存（ro_）和 assign
4. 参数/状态定义（P_）
5. 例化模块
6. 状态机实现
7. 组合逻辑
8. 时序逻辑
9. 数组赋值（放最后）
```

### 注释规范
- 模块头部注释说明功能
- 注释需要对齐
- 加减乘除等算法和逻辑处理需要注释其相关公式
- 尽量每个 always、generate、task、function 都有完整简练的注释
- 顶端写出代码主要逻辑、用途、关键状态跳转等
- 注释采用英文撰写

## §4 代码对齐规范

### 信号声明对齐
- 位宽对齐：`[X:0]` 统一缩进至相同列
- 信号对齐：变量名起始位置对齐
- 分号对齐：所有分号垂直对齐
- 注释对齐：所有 `//` 垂直对齐，注释文本对齐

### 连续赋值对齐
- assign 关键字左对齐
- 左值对齐：输出信号名起始位置对齐
- 等号对齐：所有 `=` 垂直对齐
- 右值对齐：表达式起始位置对齐
- 分号对齐：所有分号垂直对齐
- 注释对齐：所有 `//` 垂直对齐

### 特殊场景处理
- 信号名超长（超过 20 字符）时：
  - 位宽对齐可适当放宽
  - 注释可单独成行
  - 必须保持等号、分号、注释符号垂直对齐
- 推荐：超长信号名控制在 32 字符内
