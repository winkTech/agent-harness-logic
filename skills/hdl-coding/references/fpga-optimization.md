# FPGA设计优化指南

> 基于《AMD FPGA设计优化宝典：面向Vivado System Verilog》整理

---

## 一、组合逻辑优化

### 1.1 译码器代码风格

- case语句隐含优先级，但互斥条件会被综合为MUX
- LUT整合：多个布尔表达式有共同因子时，可整合到一个LUT6中

### 1.2 编码器代码风格

- 不完备的if语句会被推断为锁存器
- 不完备的case语句会被推断为锁存器

### 1.3 组合逻辑注意事项

- **避免组合逻辑环路**：组合逻辑环路会导致不稳定
- **慎用full_case和parallel_case**：可能导致综合结果与仿真不一致
- **避免锁存器**：不完备的if/case语句会产生latch

## 二、触发器优化

### 2.1 触发器资源

- **7系列**：每个SLICE包含8个触发器
- **UltraScale/UltraScale+**：每个SLICE包含16个触发器
- **Versal**：每个SLICE包含16个触发器

### 2.2 亚稳态

- **定义**：触发器输出在一段时间内处于不确定状态
- **原因**：异步信号不满足触发器的时序要求
- **解决方案**：双触发器同步器（两级FF级联）
- **约束**：使用set_max_delay约束异步路径

### 2.3 控制集

- **定义**：{CE, CLK, SR}构成触发器的控制集
- **影响**：相同控制集的触发器可以放在同一SLICE
- **优化**：减少控制集数量，提高触发器利用率

### 2.4 复位信号代码风格

- **同步复位**：使用FDRE原语
- **异步复位**：使用FDCE原语
- **设计规则**：避免既复位又置位

### 2.5 避免意外生成的锁存器

- **设计规则**：完备的if语句（包含else分支）
- **设计规则**：完备的case语句（包含default分支）

## 三、移位寄存器优化

### 3.1 移位寄存器资源

- **LUT移位寄存器**：使用SLICEM中的LUT实现
- **SRL（Shift Register LUT）**：将LUT配置为移位寄存器

### 3.2 移位寄存器代码风格

- **设计规则**：使用for循环生成移位寄存器
- **设计规则**：避免使用initial语句初始化

### 3.3 移位寄存器应用场景

- **数据延迟**：延迟数据流
- **串并转换**：串行数据转并行
- **流水线**：实现流水线结构

## 四、存储器优化

### 4.1 存储器资源

- **Block RAM**：18Kb或36Kb的双端口RAM
- **UltraRAM**：更大的存储器资源
- **分布式RAM**：使用LUT实现的RAM

### 4.2 同步FIFO代码风格

- **设计规则**：使用双端口RAM实现FIFO
- **设计规则**：使用读写指针管理FIFO

### 4.3 异步FIFO代码风格

- **设计规则**：使用格雷码处理跨时钟域指针
- **设计规则**：使用双触发器同步器同步指针

### 5.2 代码风格

- **设计规则**：使用流水线结构提高频率
- **设计规则**：利用DSP48实现乘法

## 七、布线拥塞优化

### 7.1 布线拥塞的三种类型

- **局部拥塞**：特定区域布线资源不足
- **全局拥塞**：整体布线资源紧张
- **时序拥塞**：关键路径布线延迟过大

### 7.2 利用设计流程改善布线拥塞

- **设计规则**：使用phys_opt_design命令

### 7.3 从代码层面降低布线拥塞程度

- **设计规则**：减少控制集数量
- **设计规则**：合理划分模块

## 八、时钟网络优化

### 8.1 时钟资源

- **BUFG**：全局时钟缓冲器
- **BUFH**：水平时钟缓冲器
- **BUFR**：区域时钟缓冲器

### 8.2 门锁时钟（Gated Clock）

- **定义**：使用逻辑门控制时钟的开关
- **优点**：降低功耗
- **缺点**：时钟不稳定性增强，可能产生毛刺
- **设计规则**：尽量使用器件提供的时钟控制模块
- **替代方案**：使用时钟使能信号代替门锁时钟

### 8.3 Fmax（最大时钟频率）

- **定义**：电路能够达到的最高时钟频率
- **计算公式**：Fmax = 1 / Tclk_min
- **优化方法**：缩短关键路径、使用流水线、优化布局布线

## 九、状态机优化

### 9.1 状态编码方式

- **二进制码**：使用最少的触发器，但组合逻辑较多
- **独热码（One-Hot）**：每个状态使用一个触发器，组合逻辑较少，易于时序收敛
- **格雷码（Gray Code）**：相邻状态只有一位不同，适合低功耗设计

### 9.2 状态编码选择建议

| 状态个数 | 推荐编码 | 说明 |
|---------|---------|------|
| ≤ 5 | 二进制码 | 使用最少触发器 |
| 5~50 | 独热码 | 组合逻辑少，易时序收敛 |
| > 50 | 格雷码 | 低功耗设计 |

## 十、设计优化策略

### 10.1 优化三要素

- **时序**：满足时钟频率要求
- **资源**：控制逻辑单元使用
- **功耗**：降低动态和静态功耗
- **平衡**：三者相互制约，需根据应用需求权衡

### 10.2 时序优化

- **优化目标**：设置为Speed模式
- **物理综合**：调整关键路径电路
- **寄存器复制**：降低高扇出信号延迟
- **寄存器重定时**：移动寄存器位置平衡延迟

### 10.3 资源优化

- **优化目标**：设置为Area模式
- **寄存器打包**：将不相关电路打包到同一LE
- **存储器使用**：合理使用Block RAM
- **DSP块使用**：合理使用DSP块
