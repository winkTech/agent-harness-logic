# RTL代码审查规范

> 专门针对Verilog/SystemVerilog RTL代码的审查规则，补充code-review插件的通用审查

---

## 审查清单

### 1. 时序安全检查（最高优先级）

#### 1.1 同步复位检查
- [ ] 是否使用高电平同步复位？
- [ ] 是否避免使用全局异步复位？
- [ ] 异步复位是否进行"异步复位、同步释放"处理？

#### 1.2 输入信号寄存检查
- [ ] 所有输入信号是否已寄存（ri_前缀）？
- [ ] 是否避免直接使用未经寄存的输入信号？

#### 1.3 输出信号处理检查
- [ ] 是否避免组合逻辑直接输出？
- [ ] 输出是否通过寄存器驱动（ro_前缀）？

#### 1.4 跨时钟域处理检查
- [ ] 异步输入是否双寄存器同步？
- [ ] 跨时钟域信号是否使用 `_cdc` 后缀？
- [ ] 异步复位是否进行同步处理？

### 2. 命名规范检查

#### 2.1 信号前缀检查
- [ ] 输入信号是否使用 `i_` 前缀？
- [ ] 输出信号是否使用 `o_` 前缀？
- [ ] 内部寄存器是否使用 `r_` 前缀？
- [ ] 内部连线是否使用 `w_` 前缀？
- [ ] 寄存输入是否使用 `ri_` 前缀？
- [ ] 寄存输出是否使用 `ro_` 前缀？
- [ ] 参数/状态是否使用 `P_` 前缀？

#### 2.2 特殊信号命名检查
- [ ] 时钟信号是否使用 `i_clk_xx` 格式？
- [ ] 复位信号是否使用 `i_rst_xx` 格式？
- [ ] 跨时钟域信号是否以 `_cdc` 结尾？
- [ ] 数组是否以 `_array` 结尾？

### 3. 状态机检查

#### 3.1 状态机结构检查
- [ ] 是否采用三段式状态机？
- [ ] 是否使用 `localparam` 定义状态？
- [ ] 是否包含 `default` 分支？

#### 3.2 状态编码检查
- [ ] 状态个数 ≤ 5 时是否使用二进制码？
- [ ] 状态个数 5~50 时是否使用独热码？
- [ ] 状态个数 > 50 时是否使用格雷码？

### 4. 代码结构检查

#### 4.1 模块头部注释检查
- [ ] 是否包含模块名称？
- [ ] 是否包含功能描述？
- [ ] 是否包含输入输出端口说明？
- [ ] 是否包含主要逻辑说明？

#### 4.2 代码顺序检查
- [ ] 是否按正确顺序组织代码？
  1. 模块声明和I/O定义
  2. 参数/状态定义（P_）
  3. 输入信号寄存（ri_）
  4. 输出信号寄存（ro_）和assign
  5. 例化模块
  6. 状态机实现
  7. 组合逻辑
  8. 时序逻辑
  9. 数组赋值（放最后）

### 5. 代码质量检查

#### 5.1 锁存器检查
- [ ] case语句是否添加default分支？
- [ ] if…else语句是否添加else分支？
- [ ] assign语句条件是否完整？

#### 5.2 位宽匹配检查
- [ ] 赋值等式左右位宽是否匹配？
- [ ] 有符号数和无符号数是否混合运算？
- [ ] 乘法器输出位宽是否正确？

#### 5.3 阻塞/非阻塞赋值检查
- [ ] 时序逻辑是否使用非阻塞赋值（<=）？
- [ ] 组合逻辑是否使用阻塞赋值（=）？
- [ ] 同一always语句中是否混用阻塞和非阻塞赋值？

### 6. Testbench检查

#### 6.1 文件规范检查
- [ ] 文件命名是否为 `tb_<module_name>.v`？
- [ ] 模块命名是否为 `tb_<module_name>`？
- [ ] 文件位置是否在 `02_sim/` 目录？

#### 6.2 测试结构检查
- [ ] 是否包含时钟生成？
- [ ] 是否包含超时保护？
- [ ] 测试用例是否覆盖关键场景？
- [ ] 波形输出是否配置？

## 审查流程

### 1. 自动审查（Hook触发）

```markdown
# 编写RTL代码后自动触发
1. 检查时序安全规则
2. 检查命名规范
3. 检查状态机结构
4. 检查代码结构
5. 生成审查报告
```

### 2. 手动审查（用户请求）

```markdown
# 用户请求审查时
1. 读取代码文件
2. 执行完整审查清单
3. 生成详细审查报告
4. 提供改进建议
```

## 常见问题与解决方案

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 使用全局异步复位 | 不了解同步复位优势 | 改为同步复位或异步复位同步释放 |
| 输入信号未寄存 | 不了解输入寄存重要性 | 添加ri_寄存器 |
| 组合逻辑直接输出 | 不了解输出寄存重要性 | 添加ro_寄存器 |
| 跨时钟域未同步 | 不了解亚稳态风险 | 添加双寄存器同步器 |
| 状态机缺少default | 不了解latch风险 | 添加default分支 |
| 命名不规范 | 不了解命名规范 | 按规范修改信号名 |
