# Draw Rule

## 此规则适用范围
- 使用 drawio 或者 Visio 绘制框图时
- 制作 PPT 文件时

---

## 一、文本与间距约束（防止重叠）

### 1.1 矩形框内边距
- 矩形框左右内边距 ≥ 文本高度的 2 倍
- 矩形框上下内边距 ≥ 文本高度的 0.5 倍
- 多行文本时，行间距 ≥ 文本高度的 0.3 倍
- 文字不贴框边，四周留白充足

### 1.2 矩形框最小尺寸
- 宽度 ≥ 最长行文字宽度 + 40px
- 高度 ≥ 文字总行高 + 20px
- 标题与正文在同一框内时，框高度需容纳标题 + 分隔 + 正文

### 1.3 元素间距
- 同层级相邻框之间间距 ≥ 30px
- 分组框（Container）与内部子框的间距 ≥ 15px
- 不同分组之间的间距 ≥ 分组内部间距的 2 倍

### 1.4 连线与文本
- 连线上的标签文本，必须放置在连线的水平或垂直中点，且连线在该段应为直线（不转弯）
- 连线路径避开所有矩形框的文本区域
- 禁止连线从矩形框的标题区域穿过

---

## 二、布局排布规则（版面紧凑）

### 2.1 对齐方式
- 同一层级的矩形框必须保持水平或垂直对齐（顶部/居中对齐）
- 同一列的元素宽度保持一致，同一行的元素高度保持一致
- 分支/树形结构采用对称布局，左右子节点数量尽量平衡

### 2.2 连线走线规则
- 连线遵循正交走线（水平+垂直），禁止斜线连线
- 连线转弯点距矩形框边界 ≥ 10px
- 多条平行连线之间间距 ≥ 10px，防止合并成一条
- 连线尽量采用最短路径原则，避免绕远路

### 2.3 紧凑化策略
- 在不违反内边距和元素间距的前提下，尽量缩小整体版面尺寸
- 优先采用横向布局（宽度 > 高度），充分利用屏幕宽度
- 单方向布局层级不超过 5 层，超过时考虑分页或子图

## 三、字体与颜色（画面清晰）

### 3.1 字体层级
- 图标题：18-22pt，加粗
- 模块标题（矩形框标题）：14-16pt，加粗
- 正文/描述文字：10-12pt，常规
- 连线标签：9-10pt，常规
- 同一张图内同类文字字号统一

### 3.2 颜色对比度规则（核心原则：背景偏白/浅，文字偏黑/暗）

#### 推荐配色方案（HEX 色号）
| 用途 | 推荐色号 | 说明 |
|------|----------|------|
| 画布背景 | `#FFFFFF` 或 `#FAFAFA` | 纯白或极浅灰 |
| 矩形框填充 | `#E8F0FE`（浅蓝） / `#FFF3E0`（浅橙） / `#E8F5E9`（浅绿） / `#F3E5F5`（浅紫） | 浅色系，饱和度 ≤ 30% |
| 矩形框标题背景 | `#1565C0`（深蓝） / `#EF6C00`（深橙） / `#2E7D32`（深绿） | 深色标题背景配白色文字 |
| 正文文字 | `#212121`（极深灰） / `#333333` | 接近黑色但不刺眼 |
| 标题文字 | `#FFFFFF` | 白色文字配深色标题背景 |
| 边框线 | `#90CAF9`（浅蓝） / `#BDBDBD`（浅灰） | 浅色边框 |
| 连线 | `#78909C`（蓝灰） / `#757575`（中灰） | 中性色，比边框稍深 |
| 连线标签文字 | `#37474F`（深蓝灰） | 可读性高 |

#### 禁止使用
- ❌ 浅色背景 + 浅色文字（如 `#FFF9C4` 背景配 `#FDD835` 文字）
- ❌ 深色背景 + 深色文字（如 `#1565C0` 背景配 `#0D47A1` 文字）
- ❌ 纯黑背景画布（`#000000`）
- ❌ 饱和度 > 80% 的纯色填充（如 `#FF0000` 红底）
- ❌ 相邻色块使用相近色且中间无线条区隔（如浅蓝 `#E3F2FD` 紧挨浅绿 `#E8F5E9`）

#### 通用规则
- 任何文字所在的区域，背景色亮度 ≥ 200（RGB 总和 ≥ 600），文字色亮度 ≤ 80（RGB 总和 ≤ 240）
- 矩形框填充色与文字颜色的亮度差 ≥ 128 级（0-255 灰度范围）
- 连线颜色透明度 ≤ 20%（若支持 alpha 通道）
- 同一张图内颜色数量 ≤ 5 种（不含黑白灰），避免过于花哨

## 四、Drawio 特有参数设置

- 使用drawio绘图时，必须加载/drawio-skill

### 4.1 页面与网格
- 页面方向采用横向（Landscape）
- 网格（Grid）开启，网格大小 10px
- 对齐到网格（Snap to Grid）开启

### 4.2 矩形框属性
- `whiteSpace=wrap` 开启自动换行
- `overflow=hidden` 溢出隐藏，防止文字溢出到框外
- `spacing=10` 统一设置内边距
- `rounded=1` 圆角矩形，`arcSize=10` 圆角半径

### 4.3 连线属性
- `curved=0` 禁用曲线连线，使用正交连线
- `jumpStyle=arc` 连线交叉处使用弧形跳线
- `exitX/exitY` 和 `entryX/entryY` 固定连线的出入点，避免连线穿过文字区域
- 连线端点的箭头方向明确统一

## 五、生成前的检查清单（AI 必须自查）

绘制完成后 AI 应逐项自查，有一项不满足就需调整：

- [ ] 所有矩形框的高度是否足以容纳内部全部文字（含标题+正文）？
- [ ] 任意两个矩形框之间的间距是否 ≥ 30px？
- [ ] 是否有连线穿过矩形框的标题区域？
- [ ] 是否有文字溢出矩形框之外（overflow hidden 后仍然可见）？
- [ ] 同行/同列的矩形框是否保持了对齐？
- [ ] 同一层级字体大小是否统一？
- [ ] 连线是否采用了正交走线（非斜线）？
- [ ] 整体版面是否做到了尽量紧凑而不空旷？
- [ ] 是否有文字被连线覆盖导致不可读？
