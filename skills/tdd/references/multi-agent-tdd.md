# 多 Agent TDD 分解

大型功能按接口契约拆分为独立任务，每个子 Agent 独立执行 TDD 循环。

## 流程

1. **架构师 Agent**: 定义模块接口和契约
2. **Planner Agent**: 按接口拆分独立任务
3. **N × 开发者 Agent**: 各执行完整 TDD（RED→GREEN→REFACTOR）
4. **审查 Agent**: 两阶段审查（规范合规 → 代码质量）
5. **集成 Agent**: 合并验证整体测试通过

## TDAID 阶段映射

| 阶段 | 参与者 | 产出 |
|:----|:-------|:-----|
| 1. 需求分析 | 架构师 | 接口契约、验收标准 |
| 2. 测试规划 | QA | 测试场景列表 |
| 3. 并行开发 | N 开发者 | 各模块实现 + 测试 |
| 4. 审查 | 审查者 | 合规 + 质量报告 |
| 5. 集成 | 集成者 | 全量测试通过 |
