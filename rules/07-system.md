# 系统操作规则

> L1 优先级：涉及安装/下载/文件操作时自动加载。

## 软件安装规则

安装任何软件时，**默认安装到 D 盘**（或其他非系统盘），**不得装到 C 盘**，除非用户明确说"装到 C 盘"。

**原因**：C 盘是系统盘，空间宝贵；软件占用大，容易挤爆；重装系统时 C 盘软件全部丢失。

**操作流程**：
1. 安装前确认 D 盘有足够空间
2. 安装时指定路径 `D:\Program Files\<AppName>` 或 `D:\<AppName>`
3. 软件强制装 C 盘 → 通知用户决定
4. 例外：用户明确要求 / 系统驱动必须驻留

## 文件下载规则

下载文件（非安装包）时，优先选择以下位置：
- 文档类 → `D:\Documents\`
- 项目文件 → 项目所在盘根目录
- 临时文件 → 系统临时目录

## 禁止操作

- 不以管理员身份运行未知安装包
- 不修改系统环境变量 PATH（除非用户明确要求）
- 不写入 `C:\Windows\System32` 等系统目录
