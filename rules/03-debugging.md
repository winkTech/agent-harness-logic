# 调试规则

> L2 优先级：遇到错误/调试场景时按需加载。

- 使用 `/debugging` skill 进行系统化调试
- 使用 `/rag-skill` 检索知识库中的领域知识
- 失败经验应记录到 `memory/errors/`
- 详细方法论见 `skills/debugging/SKILL.md`

## 系统化调试步骤

遇到错误/异常时按以下顺序执行：
1. **复现并记录上下文** — 记录完整错误信息、输入数据、条件
2. **缩小范围（二分法/隔离法）** — 逐级定位问题所在模块/行
3. **提出假设并验证** — 对每个假设写出预期结果，逐一验证
4. **修复并确认** — 实施最小修复，确认问题消失
5. **记录教训** — 将根因和修复写入 memory/errors/

### 违反后果
未记录失败经验到 memory/errors/ → 同类错误可能重复发生，浪费调试时间。
