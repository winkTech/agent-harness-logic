# RAG Skill Workflow

知识库检索问答的标准流程。

---

## Phase 1: 意图识别

**目的**: 判断用户真正需要什么，选择检索策略

1. **解析问题核心** — 提取领域（comm/dsp/fpga/protocol）和需求类型（概念/实现/配置/排错）
2. **选择检索模式**:
   - **精确查找** — 已知文件名或关键词 → 直接读取
   - **概念理解** — "什么是 X" → 标签优先检索
   - **方案设计** — "如何实现 Y" → 渐进加载（先概要后细节）
   - **排错诊断** — "Z 报错" → 按错误码/现象匹配
3. **确定范围** — 限定知识域，避免无关文档

**输出**: 检索计划（模式 + 范围）

---

## Phase 2: 渐进式加载

**目的**: 先卡片后详情，避免一次加载过多

1. **标签匹配** — 按 `knowledge/INDEX.md` 中的标签体系命中目标卡片
2. **卡片浏览** — 读取匹配卡片的摘要和链接
3. **深度加载** — 根据卡片指引加载具体文档
4. **置信度检查** — 答案是否完整？是否需要跨域检索？
5. **补充检索** — 必要时回退到 rag-skill 的全文搜索

**输出**: 检索到的知识片段

---

## Phase 3: 综合回答

**目的**: 将检索结果整合为清晰、可操作的答案

1. **归纳核心** — 提取与问题最相关的 3-5 个要点
2. **代码/配置示例** — 如有相关设计或代码，附上可直接使用的片段
3. **注明来源** — 标注文档路径，方便用户深入阅读
4. **限制说明** — 明确知识库覆盖范围，超出部分给出建议

**输出**: 结构化的回答
