# Python 概览

## 特点
- **解释型语言**：不需要编译，直接运行
- **动态类型**：变量无需声明类型
- **面向对象**：一切皆对象
- **丰富的生态**：PyPI 拥有超过 20 万个第三方包
- **应用领域**：数据科学、机器学习、Web 开发、自动化脚本、科学计算
