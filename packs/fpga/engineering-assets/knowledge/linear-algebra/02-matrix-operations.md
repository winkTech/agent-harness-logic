# 矩阵运算

## 矩阵定义
m×n 矩阵: A ∈ ℝ^{m×n}，m 行 n 列

```python
A = np.array([[1, 2, 3],
              [4, 5, 6]])  # shape (2, 3)
```

## 矩阵乘法
C_{m×p} = A_{m×n} × B_{n×p}
- (i,j) 元素: Cᵢⱼ = ∑ₖAᵢₖBₖⱼ
- **不满足交换律**: AB ≠ BA（一般情况）

### 四种视角
1. **逐元素**: Cᵢⱼ = A 第 i 行 · B 第 j 列
2. **列视角**: C 的列是 A 的列的线性组合
3. **行视角**: C 的行是 B 的行的线性组合
4. **外积**: C = ∑ₖA[:,k] · B[k,:]

```python
A @ B           # 矩阵乘法（推荐）
np.dot(A, B)    # 矩阵乘法
A * B           # 对应元素相乘（Hadamard 积）
```

## 特殊矩阵
| 类型 | 定义 | 性质 |
|------|------|------|
| 单位矩阵 I | Iᵢⱼ = δᵢⱼ | AI = IA = A |
| 对角矩阵 D | Dᵢⱼ = 0 (i≠j) | 逆=对角取倒数 |
| 对称矩阵 | A = Aᵀ | 实对称⇒正交对角化 |
| 正交矩阵 Q | QᵀQ = QQᵀ = I | 保范变换 |
| 上三角 U | i>j 时 Uᵢⱼ=0 | 行列式=对角线积 |
| 正定矩阵 | xᵀAx > 0 (∀x≠0) | 全部特征值>0 |
| 分块矩阵 | 大矩阵由子矩阵块组成 | 分块乘法、Schur 补 |

## 矩阵分解一览
| 分解 | 形式 | 条件 | 应用 |
|------|------|------|------|
| LU | A = LU | 方阵 | 解线性方程组 |
| QR | A = QR | 任意 | 最小二乘、特征值 |
| Cholesky | A = LLᵀ | 对称正定 | 数值稳定 |
| EVD | A = VΛV⁻¹ | 方阵可对角化 | PCA、谱分析 |
| SVD | A = UΣVᵀ | 任意矩阵 | 降维、伪逆、压缩 |

## 重要性质
- (AB)ᵀ = BᵀAᵀ
- (AB)⁻¹ = B⁻¹A⁻¹（A,B 可逆）
- **迹**: tr(A) = ∑Aᵢᵢ
- det(AB) = det(A)·det(B)
- rank(A) = rank(Aᵀ) = rank(AᵀA) = rank(AAᵀ)
