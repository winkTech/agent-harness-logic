# 数列与级数

## 基本概念
- **数列**: 按一定次序排列的数的序列 {a₁, a₂, a₃, ...}
- **通项公式**: aₙ = f(n)，第 n 项的表达式
- **递推公式**: aₙ₊₁ = f(aₙ)，由前项推后项

## 等差数列
- aₙ = a₁ + (n-1)d, d 为公差
- 前 n 项和: Sₙ = n(a₁ + aₙ)/2 = n[2a₁ + (n-1)d]/2

## 等比数列
- aₙ = a₁·rⁿ⁻¹, r 为公比
- 前 n 项和: Sₙ = a₁(1-rⁿ)/(1-r) (r ≠ 1)
- 无穷级数（|r| < 1）: S = a₁/(1-r)

## 数列极限
- lim_{n→∞} aₙ = L: n 趋近无穷时 aₙ 无限接近 L
- 常用极限: lim_{n→∞} 1/n = 0, lim_{n→∞} (1+1/n)ⁿ = e

## 级数
- 收敛: 部分和序列有极限
- 发散: 部分和序列无极限
- 调和级数: ∑1/n 发散
- 几何级数: ∑rⁿ，|r|<1 时收敛
- p-级数: ∑1/nᵖ，p>1 收敛，p≤1 发散

## 函数项级数
- 幂级数: ∑aₙ(x-c)ⁿ，收敛半径 R = 1/lim|aₙ|^{1/n}
- Taylor 展开: f(x) = ∑f⁽ⁿ⁾(a)(x-a)ⁿ/n!
