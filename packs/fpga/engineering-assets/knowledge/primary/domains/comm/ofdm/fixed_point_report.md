# OFDM 发射机 定点量化报告

## 1. 关键节点分析

### 1.1 信号路径节点

```
Node1         Node2         Node3         Node4          Node5
ModSym ──→ SubcarrierMap ──→ IFFT ──→ CP Insert ──→ Output
  ↑            ↑              ↑         ↑              ↑
QPSK符号    频域网格       时域采样    加CP后        最终输出
```

### 1.2 各节点动态范围分析

#### Node1: 调制符号

QPSK 符号值: $(\pm 1 \pm j) / \sqrt{2}$

| 指标 | I路 | Q路 |
|------|-----|-----|
| 最大值 | +0.707 | +0.707 |
| 最小值 | -0.707 | -0.707 |
| 动态范围 | 1.414 | 1.414 |
| 需整数位 | 1 (符号位+1) | 1 |

**结论:** Q1.14 (2整数+14小数 = 16bit) 足够，留1bit余量

#### Node3: IFFT输出 (峰值关键)

IFFT 公式: $x[n] = \frac{1}{\sqrt{N}} \sum_{k=0}^{N-1} X_k \cdot e^{j2\pi kn/N}$

当 N=64, 所有子载波同相位时:
- 峰值: $|x[n]|_{max} = \sqrt{N} \cdot |X_k|_{max} = 8 \times 0.707 = 5.66$
- PAPR 典型值 (QPSK): 10-12dB
- 99.9% 概率幅度 < 4×RMS

| 指标 | 估计值 |
|------|--------|
| RMS | ~1.0 (归一化) |
| 峰值(99.9%) | ~4.0 |
| 理论最大 | 5.66 |
| 需整数位 | 3 (含符号位) |

**结论:** Q3.13 (3整数+13小数 = 16bit)，3bit可表示 ±4，覆盖99.9%情况

#### Node5: 最终输出

同 Node4 (CP 不改变幅度)，Q3.13

### 2.2 IFFT 缩放策略

| 策略 | 实现 | 优点 | 缺点 |
|------|------|------|------|
| 块浮点(BFP) | 每级检测溢出右移 | 精度最高 | 控制复杂；引入随符号变化的指数 |
| **固定逐级右移** | 指定级固定÷2 | 定尺度，可位真镜像 | 小信号精度损失 |
| 输入缩放 | 输入前右移 | 最简单 | 整体SNR下降 |

> **决策变更 (2026-08-01, ADR-004 阶段3)**：原推荐 BFP，理由是"Xilinx FFT IP 默认模式"。
> ADR-004 已裁决弃用该 IP 改自研 R2²SDF，该理由随之失效；且 BFP 的逐符号指数是
> **变尺度**，与 golden `ifft_chain` 的 `ifft(x)·sqrt(N)` 定尺度契约冲突，会使
> G-B-03 要求的 0 容差位真镜像无法成立。故改采**固定逐级右移**。

**当前调度（`ofdm_tx_top` 0.3.0 / `ifft64_sdf` 的单一事实源，golden 镜像以此为准）：**

| 环节 | 运算 | 说明 |
|:-----|:-----|:-----|
| 内部位宽 | s20 | 频域 Q2.14 输入零扩展至 20 位 |
| 级 1/3/5 (BF2I) | 不缩放 | 无乘法器 |
| 级 2/4/6 (BF2II) | 蝶形后 `(x+1)>>>1` | 三级共 ÷8，达成 `Σ X·U^{nk}/8` = `ifft(x)·√64` 标定 |
| 旋转乘 (级 2/4 后) | `(v·w + 8192)>>>14` | w = `round(cos/sin(2πk/64)·16384)`，Q2.14 |
| 平凡因子 (BF2II) | `(re,im) → (-im,re)` | `j^{n1}`，无乘法 |
| 输出级 | `(x+1)>>>1` + s16 饱和 | Q2.14 → Q3.13 的**格式转换**，非额外缩放 |

净标定为 ÷8，与 §2.1 的 Q2.14→Q3.13 位置推导一致。

**偏离本表即为 RTL 缺陷**：本表是需求侧决策，位真镜像 (`models/comm/ofdm/src/rtl_mirror_tx.m`)
按本表实现；cosim 失配时应修 RTL，不得反过来改镜像或本表去迁就实现。

### 2.3 溢出分析

| 节点 | 饱和概率(16bit) | 处理方式 |
|------|----------------|----------|
| Node1 | 0% | 幅度固定QPSK，不溢出 |
| Node2 | 0% | 48子载波相加有溢出风险，BFP管理 |
| Node4 | <0.1% | BFP自动缩放 |

### 2.4 舍入策略

| 策略 | 实现代价 | EVM退化(@16bit) | 推荐 |
|------|----------|-----------------|------|
| truncation | 0 | ~0.5dB | 不推荐 |
| rounding | +少量LUT | ~0.1dB | ✅ 推荐 |
| convergent rounding | +较多LUT | ~0.05dB | 需要高EVM时 |

**采纳 (2026-08-01)**：全部缩放点一律 rounding —— 级 2/4/6 的 `(x+1)>>>1`、
旋转乘的 `+8192` 预偏置、输出级的 `(x+1)>>>1` 均为向上偏置的二进制舍入。
0.2.0 的级移位曾为纯截断（`>>>1`），与本表推荐不符，已在 0.3.0 随 R2²SDF
重排一并改正。convergent rounding 未采用：本设计的量化偏差实测已在 ±2 LSB，
不值得为 ~0.05dB 增加逻辑。
