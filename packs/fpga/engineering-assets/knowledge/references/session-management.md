# 会话管理指南

> 上下文膨胀监控与应对策略

---

## 预警信号

| 信号 | 正常值 | 警戒值 | 危险值 |
|------|--------|--------|--------|
| **首 token 延迟** | < 2s | 2-5s | > 5s |
| **输出速度** | > 30 token/s | 15-30 token/s | < 15 token/s |
| **工具调用** | < 1s | 1-3s | > 3s |
| **对话轮数** | < 20 轮 | 20-40 轮 | > 40 轮 |

---

## 信号检测方法

**1. 首 token 延迟**
```
发送消息后，观察 AI 开始输出第一个字的时间
正常：几乎立即开始
异常：明显等待后才开始
```

**2. 输出速度**
```
观察 AI 输出文字的流畅度
正常：连续快速输出
异常：断断续续，有明显停顿
```

**3. 工具调用卡顿**
```
调用读文件、搜索等工具时
正常：工具结果快速返回
异常：工具调用后长时间无响应
```

## 应对措施流程图

```
发现预警信号
    │
    ├─→ 轻度（2-5s 延迟）
    │       │
    │       └─→ /compact 压缩上下文
    │               │
    │               └─→ 继续工作
    │
    ├─→ 中度（5-10s 延迟）
    │       │
    │       ├─→ 1. 保存当前进度到记忆
    │       ├─→ 2. /compact 尝试压缩
    │       └─→ 3. 若无效，开新会话
    │
    └─→ 重度（>10s 延迟）
            │
            ├─→ 1. 立即保存进度
            ├─→ 2. 开新会话
            └─→ 3. 从记忆恢复继续
```

---

## 具体操作步骤

**情况 1：/compact 能解决**
```
1. 输入 /compact
2. 等待压缩完成（通常 10-30 秒）
3. 验证：发送测试消息，观察延迟
4. 若正常，继续工作
```

**情况 2：需要开新会话**
```
1. 保存进度：
   - 记录当前任务状态
   - 记录未完成的工作
   - 记录重要决策

2. 开新会话：
   - 关闭当前会话
   - 重新启动 Claude Code

3. 恢复上下文：
   - 读取 memory/MEMORY.md 索引
   - 找到相关工作记忆
   - 继续任务
```

---

## 预防性措施

| 时机 | 操作 | 目的 |
|------|------|------|
| 对话 15 轮后 | 主动 /compact | 防止膨胀 |
| 切换任务前 | 保存进度 + 新会话 | 隔离上下文 |
| 长时间工作后 | 休息 + 新会话 | 重置状态 |
| 每天结束时 | 清理记忆 + 归档 | 保持整洁 |
