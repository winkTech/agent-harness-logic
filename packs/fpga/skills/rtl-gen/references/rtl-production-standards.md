# 生产级 RTL 规范（共享）

所有 `/rtl-gen` 生成的 RTL 代码必须遵守以下规范。

## §1 时序安全（最高优先级）

### 1.1 复位
- 使用**同步高有效复位** `i_rst`
- 避免全局异步复位。必须用异步复位时，采用**异步复位同步释放**
- 初始值通过复位设置，不在声明中赋初值

### 1.2 输入信号寄存
- 所有输入信号在模块入口寄存为 `ri_` 前缀
- 禁止直接使用未经寄存的输入

### 1.3 输出寄存器驱动
- 所有输出必须通过寄存器驱动（`ro_` 前缀）
- 避免组合逻辑直接输出

### 1.4 跨时钟域
- 异步输入必须双寄存器同步 + `_cdc` 后缀
- 多-bit 跨时钟域使用格雷码或握手机制

### 1.5 数据-使能对
- 数据必须与有效信号（valid/enable）成对传递
- 不允许"数据在那里就是有效的"假设

### 1.6 禁止锁存器
- `case` 必须有 `default`
- `if-else` 必须有 `else`
- `assign` 条件必须完整

## §2 命名规范

### 2.1 信号前缀

| 前缀 | 含义 | 示例 |
|:----|:-----|:-----|
| `i_` | 模块输入 | `i_clk`, `i_rst` |
| `o_` | 模块输出 | `o_dout`, `o_valid` |
| `ri_` | 寄存后的输入 | `ri_data`, `ri_wr_en` |
| `ro_` | 寄存后的输出 | `ro_dout`, `ro_valid` |
| `r_` | 内部寄存器 | `r_wr_ptr`, `r_rd_ptr` |
| `w_` | 内部连线 | `w_full`, `w_empty` |
| `P_` | 参数/状态 | `P_IDLE`, `P_DATA_W` |

### 2.2 特殊信号
- 时钟: `i_clk_xx`（如 `i_clk_100m`）
- 复位: `i_rst`（高有效同步）
- 跨时钟域: `sig_cdc`
- 数组: `_array` 结尾

## §3 代码结构

### 模块排列顺序
```
模块声明和 I/O 定义
↓ 参数/状态定义（P_ localparam）
↓ 输入信号寄存（ri_）
↓ 内部寄存器声明（r_）
↓ 内部连线声明（w_）
↓ 例化子模块
↓ 组合逻辑（always_comb / assign）
↓ 时序逻辑（always_ff）
↓ 输出寄存（ro_）和 assign
```

### 模块划分原则
- 每模块不超过 300 行
- 每个 `always` 块不超过 50 行
- 分离控制通路和数据通路

## §4 位宽与符号

- 赋值左右位宽必须匹配
- 使用 `$clog2()` 计算地址/计数位宽
- 禁止有符号和无符号数混合运算
- 乘法器输出位宽 = 输入位宽之和
- `localparam P_ADDR_W = $clog2(P_DEPTH);`

## §5 阻塞/非阻塞赋值

| 块类型 | 赋值 | 场景 |
|:------|:----|:------|
| 时序逻辑 `always_ff @(posedge i_clk)` | `<=` 非阻塞 | 所有寄存器 |
| 组合逻辑 `always_comb` | `=` 阻塞 | 中间计算 |
| **禁止** | 混用 | 同一 always 块 |

## §6 参数化设计

- 使用 `parameter` 或 `localparam` 定义所有可配参数
- 位宽、深度、阈值等必须参数化
- 模块例化时使用 `#(.PARAM(VALUE))` 传参

## §7 注释规范

### 模块头注释
```verilog
//=============================================================================
// Module Name: <module_name>
// Description: <功能描述>
// Author:      <author>
// Created:     <date>
// References:  <参考手册>
//=============================================================================
```

### 关键逻辑注释
- 状态机每个状态标注含义
- 跨时钟域标注同步机制
- 复杂组合逻辑说明算法

## §8 生成后验证

所有生成的 RTL 必须经过:

1. **语法检查**: `vlog -lint <file>` 或 `iverilog -g2012 -t null -s <top> <file>`
2. **编译检查**: `iverilog -g2012 -o sim.vvp <file>.v`
3. **Lint 规则**: 通过 `hdl-coding` skill 定义的 lint 门禁
