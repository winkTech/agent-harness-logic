# 认知层 — 7 种推理模式

> 触发条件已在 `00-core.md`（L0，始终加载）中定义。本文件只保留模式详细说明。

| # | 模式 | 适用 | 方法 | 输出 |
|:--|:-----|:-----|:-----|:-----|
| 1 | 根因分析 | 修 bug、调试 | 5-Why + 扫同类模式 | 根因 + 修复 + 预防 |
| 2 | 第一性原理 | 新建功能、设计 | 质疑假设 → 删除非本质 → 简化 | 最小方案 |
| 3 | 减法 | 重构、清理 | 删除优先，问"不做什么" | 删减清单 |
| 4 | 搜索优先 | 根因未知、有印象 | 先查历史/文档/代码索引 | 检索结论 |
| 5 | 倒推 | 新模块设计、需求不清 | 从终态倒推 → 接口 → 实现 | 接口定义 |
| 6 | 证据驱动 | 性能优化、方案选型 | 先 baseline，再改再测 | 对比数据 |
| 7 | 闭环 | 默认模式、多步骤 | 目标 → 过程 → 结果 → 复盘 | 进度报告 |

## 切换声明

```
🔄 切换到 [模式名] 模式
原因：检测到 [信号]，当前 [原模式] 未产生有效进展
```

## 状态持久化

```bash
node ~/.claude/engine/scripts/runtime-state.cjs set-mode <模式名>
node ~/.claude/engine/scripts/runtime-state.cjs bump-failure  # 如果原模式失败
```
