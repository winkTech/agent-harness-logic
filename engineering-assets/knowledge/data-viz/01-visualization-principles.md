# 数据可视化设计原则

## 有效 vs 低效可视化
**有效**: 高信息密度、清晰、专业、简洁、准确、促进思考
**低效**: 信息过载、低分辨率、设计混乱、配色失效、缺乏上下文

## 图表类型选择
| 数据类型 | 推荐图表 | Book2 章节 |
|---------|---------|-----------|
| 趋势/时间序列 | 折线图 (Ch08) | 连续数据变化 |
| 分布 | 直方图/KDE (Ch10) | 单变量分布 |
| 相关性 | 散点图/热图 (Ch07, Ch11) | 两变量关系 |
| 组成/比例 | 饼图/堆叠图 (Ch07) | 部分 vs 整体 |
| 排名/比较 | 柱状图 (Ch07) | 类别间比较 |
| 地理 | 地图 (Ch14) | 空间数据 |
| 高维 | 平行坐标/散点矩阵 (Ch27-29) | 多变量 |
| 网络/关系 | 网络图 (Ch36) | 节点与边 |

## 布局原则
- **F 型 / Z 型阅读模式**: 重要信息放在左上和中上
- **留白**: 让图表呼吸
- **对齐**: 元素间保持视觉对齐
- **一致性**: 同一报告中的图表风格统一

## 色彩
| 颜色映射类型 | 适用场景 | 示例 |
|-------------|---------|------|
| 序列 (Sequential) | 连续数值 | 温度、海拔 |
| 发散 (Diverging) | 有中心点的值 | 相关性、偏离 |
| 定性 (Qualitative) | 分类变量 | 不同类别 |
| 循环 (Cyclic) | 角度/周期 | 方向、时间 |

### 配色建议
- 色盲友好: 避免只用红绿，改用蓝橙
- 不超过 6-8 种区分色
- 用饱和度/明度增加层次，而非只靠色相
