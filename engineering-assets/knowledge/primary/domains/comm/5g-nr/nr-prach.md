## 1. NR PRACH 概述

### 1.1 PRACH 在随机接入中的作用

PRACH (Physical Random Access Channel) 是 UE 发起网络接入的唯一上行信道。UE 通过 PRACH 发送前导码 (preamble) 向 gNB 表明自己的存在, gNB 检测到前导后回复 RAR (Random Access Response), 完成初始同步。

两种接入模式:

| 接入模式 | 触发方 | 前导分配 | 典型场景 |
|:---------|:------|:---------|:---------|
| Contention-based (CBRA) | UE 自主选择 | UE 从公共前导池随机选取 | 初始接入、RRC 重建、上行失步 |
| Non-contention-based (CFRA) | gNB 分配 | gNB 通过 RRC/PDCCH order 指定专用前导 | 切换、波束失败恢复、SI 请求 |

### 1.2 4-step RACH vs 2-step RACH

NR 支持两种 L1 随机接入过程类型:

**Type-1: 4-step RACH (传统, 基于 3GPP Release 15 基线)**

```
UE                                          gNB
 │                                            │
 │──── Msg1: PRACH Preamble ────────────────→│  UE 发送前导码
 │                                            │  gNB 检测 → TA + UL Grant
 │←─── Msg2: RAR (PDSCH) ────────────────────│  RA-RNTI 加扰, TA Cmd + UL Grant
 │                                            │
 │──── Msg3: PUSCH (RRC Conn Request) ──────→│  UE 发送标识
 │                                            │  gNB 解码并回复竞争解决
 │←─── Msg4: Contention Resolution ──────────│  竞争解决完成
 │                                            │
```

**Type-2: 2-step RACH (Release 16 引入, 低时延)**

```
UE                                          gNB
 │                                            │
 │──── MsgA: PRACH Preamble + PUSCH 负载 ───→│  前导 + 数据合并发送
 │                                            │  gNB 联合检测
 │←─── MsgB: RAR + 竞争解决 ────────────────│  合并回复
 │                                            │
```

| 特性 | Type-1 (4-step) | Type-2 (2-step) |
|:-----|:---------------|:----------------|
| 消息交换 | 4 次 | 2 次 |
| 接入时延 | ~15-20 ms (FR1) | ~5-10 ms (FR1) |
| UE 复杂度 | 低 | 中 (需 MsgA 联合发送) |
| gNB 复杂度 | 低 | 高 (需联合检测) |
| 适用场景 | 普通接入 | URLLC / 小包传输 |
| 规范引入 | Release 15 | Release 16 |

### 1.3 PRACH 序列基础

NR PRACH 前导基于 **Zadoff-Chu (ZC) 序列**, 核心性质:

$$x_u(n) = e^{-j\frac{\pi u n (n+1)}{L_{RA}}}, \quad 0 \le n < L_{RA}$$

其中 $L_{RA}$ 为序列长度 (长序列 839, 短序列 139), $u$ 为根序列索引。

ZC 序列关键特性:

| 特性 | 含义 | 工程价值 |
|:-----|:----|:---------|
| 恒定幅度 | $|x_u(n)| = 1$ | PAPR = 0 dB, 功放效率最大化 |
| 自相关 | 零自相关区 (ZACZ) | 循环移位版本的互相关为 0, 支持多 UE 复用 |
| 互相关 | $|R_{u,v}| = 1/\sqrt{L_{RA}}$ | 不同根序列间低互相关 |
| DFT 不变性 | ZC 序列的 DFT 仍为 ZC 序列 | 频域实现高效: 发送/检测均在频域完成 |

**循环移位 (Cyclic Shift)**:

同一根序列 $u$ 通过循环移位 $C_v$ 生成多个前导码:

$$x_{u,v}(n) = x_u((n + C_v) \bmod L_{RA})$$

每个小区可配置 64 个前导码, 通过根序列 + 循环移位组合产生。

## 2. PRACH 格式完整表

### 2.1 长前导格式 (Long Preamble, $L_{RA}=839$)

与 LTE 兼容, 用于 FR1 (< 6 GHz) 宏小区覆盖:

| 格式 | SCS (kHz) | $T_{SEQ}$ ($\mu$s) | $T_{CP}$ ($\mu$s) | 总长 (ms) | 支持小区半径 | 典型用途 |
|:-----|:---------:|:-------------------:|:------------------:|:---------:|:------------|:---------|
| **0** | 1.25 | 800 | 103.1 | 1.0 | ~14 km | FR1 普通城区 (与 LTE F0 相同) |
| **1** | 1.25 | 800 | 684.4 | 2.0 | ~77 km | FR1 大型小区 (与 LTE F1 相同) |
| **2** | 1.25 | 1600 | 203.1 | 2.0 | ~29 km | FR1 中等覆盖 + 增强 (与 LTE F2 相同) |
| **3** | 1.25 | 1600 | 684.4 | 3.0 | ~107 km | FR1 超远覆盖 (与 LTE F3 相同) |

**长前导参数公式**:
- $T_{SEQ} = L_{RA} \cdot T_s / \kappa = 839 \cdot T_c \cdot \kappa \cdot L_{RA\_factor}$
  - $\kappa = T_s / T_c = 64$, $T_c = 1/(480\text{kHz} \cdot 4096) \approx 0.509$ ns
  - Format 0/1: $L_{RA\_factor} = 1$ (单次 ZC); Format 2/3: $L_{RA\_factor} = 2$ (两次 ZC 重复)
- $T_{CP} = (N_{CP}^{RA} + n_{RA}) \cdot T_c \cdot \kappa \cdot 16$
- 小区半径 $R = (T_{CP} \times c) / 2$, 其中 $c = 3 \times 10^8$ m/s

### 2.2 短前导格式 (Short Preamble, $L_{RA}=139$)

NR 全新引入, 用于 FR1 中小小区和 FR2 (mmWave):

#### A 系列: 仅含 CP + 单次序列

| 格式 | SCS (kHz) | $T_{SEQ}$ ($\mu$s) | $T_{CP}$ ($\mu$s) | 总长 (sym) | 适用 |
|:-----|:---------:|:-------------------:|:------------------:|:----------:|:-----|
| **A1** | 15 / 30 | 9.375 / 4.688 | 9.375 / 4.688 | 2 | FR1 小小区 |
| **A2** | 15 / 30 / 60 | 9.375 / 4.688 / 2.344 | 18.75 / 9.375 / 4.688 | 3 / 4 | FR1/FR2 |
| **A3** | 15 / 30 / 60 | 9.375 / 4.688 / 2.344 | 28.125 / 14.063 / 7.031 | 4 / 6 | FR1/FR2 |

#### B 系列: CP + 序列 + GP (含 GP, 适合 TDD)

| 格式 | SCS (kHz) | $T_{SEQ}$ ($\mu$s) | $T_{CP}$ ($\mu$s) | $T_{GP}$ ($\mu$s) | 总长 (sym) | 适用 |
|:-----|:---------:|:-------------------:|:------------------:|:-----------------:|:----------:|:-----|
| **B1** | 15 / 30 | 9.375 / 4.688 | 9.375 / 4.688 | 9.375 / 4.688 | 3 | FR1 |
| **B2** | 15 / 30 / 60 | 18.75 / 9.375 / 4.688 | 9.375 / 4.688 / 4.688 | 18.75 / 9.375 / 4.688 | 5 / 6 | FR1/FR2 |
| **B3** | 15 / 30 / 60 | 28.125 / 14.063 / 7.031 | 9.375 / 4.688 / 2.344 | 18.75 / 9.375 / 4.688 | 6 / 7 | FR1/FR2 |

#### C 系列: 仅含 CP + 两次序列重复

|:-----|:---------:|:-------------------:|:------------------:|:----------:|:-----|
| **C0** | 15 / 30 / 60 | 18.75 / 9.375 / 4.688 | 18.75 / 9.375 / 4.688 | 4 / 6 | FR1/FR2 |
| **C2** | 15 / 30 / 60 / 120 | 37.5 / 18.75 / 9.375 / 4.688 | 37.5 / 18.75 / 9.375 / 4.688 | 8 / 12 | FR1/FR2 |

### 2.3 Format B4 特殊说明

Format B4 是 NR Release 15 中序列重复次数最多的短前导格式, 其特殊性:

| 特性 | 细节 |
|:-----|:-----|
| 序列重复因子 | 12 (同一序列在时域重复 12 次) |
| 总符号数 (30 kHz SCS) | 18 个 OFDM 符号 (~642 $\mu$s) |
| 适用 SCS | 15/30/60/120 kHz |
| 主要应用 | FR2 大路径损耗补偿 (通过重复积累能量) |
| 小区覆盖 (FR2) | 可达 500~1000m (mmWave 小区典型半径) |
| 序列长度 | 139 (短序列) |

**工程考虑**: B4 的 12 次重复在接收机侧提供 ~10.8 dB 的处理增益 ($10\log_{10}(12)$), 是 FR2 高路径损耗环境下 gNB 检测 PRACH 的关键手段。

## 3. 频域 PRACH 配置

### 3.1 PRACH 频域位置 (msg1-FDM)

PRACH 在频域的占用通过 **msg1-FrequencyStart** 和 **msg1-FDM** 两个 RRC 参数配置:

| 参数 | RRC 字段 | 取值 | 含义 |
|:-----|:---------|:-----|:-----|
| 频域起始 PRB | `msg1-FrequencyStart` | 0..(N_size_BWP-1) | PRACH 起始 PRB 在 BWP 内的偏移 |
| 频分复用数 | `msg1-FDM` | 1, 2, 4, 8 | 同一时域 RO 上频域 PRACH 机会数 |

**频域 PRACH 配置表**:

| msg1-FDM | 频域位置数 | PREAMBLE 总数 (每 SSB) | 符号/时隙开销 |
|:--------:|:---------:|:----------------------:|:------------:|
| 1 | 1 | 64 | 低 |
| 2 | 2 | 128 | 中 |
| 4 | 4 | 256 | 高 |
| 8 | 8 | 512 | 高 (FR2 常用) |

### 3.2 PRACH 与 SSB 关联

gNB 通过 **SSB-RO 关联** 实现初始波束获取:

```
SSB #0 ──→ RO #0 (时隙 0, freq 0)
     └───→ RO #1 (时隙 0, freq 1)
     └───→ RO #2 (时隙 1, freq 0)
     
SSB #1 ──→ RO #3 (时隙 2, freq 0)
     └───→ RO #4 (时隙 2, freq 1)
     ...
```

| 参数 | RRC 字段 | 说明 |
|:-----|:---------|:-----|
| 每 SSB 的 RO 数 | `ssb-perRACH-OccasionAndCB-PreamblesPerSSB` | {1/8, 1/4, 1/2, 1, 2, 4, 8, 16} |
| 每 RO 的 CB-Preamble 数 | 同上联合编码 | 关注值 < 64 时为 N, 否则 64 |
| SSB→RO 映射周期 | `ssb-periodicityServingCell` | {5, 10, 20, 40, 80, 160} ms |

**关键规则**: `ssb-perRACH-Occasion` < 1 时, 多个 SSB 共享同一个 RO (每 SSB 的前导数少于 64); > 1 时, 一个 SSB 对应多个 RO (FR2 典型配置, 支持波束扫描)。

### 3.3 RACH Occasion (RO) 密度

一个 **RACH Occasion (RO)** 是一个时频资源块, 承载一组前导码。RO 在时域和频域上周期性出现:

```
RO 配置周期 (PRACH Configuration Index):
   TDD: 每 10ms 帧内 1~10 个 RO (取决于上行符号数)
   FDD: 每子帧可配 1 个 RO (Format 0)

RO 密度计算:
  N_RO_per_frame = N_slot * N_sym_per_slot / N_sym_per_RO * msg1-FDM
```

| FR | 典型 PRACH Configuration Index | RO 周期 | msg1-FDM | 每帧 RO 总数 |
|:---|:------------------------------|:--------|:--------:|:-----------:|
| FR1 (TDD, 30 kHz SCS) | 98 (格式 A2) | 10 ms | 4 | 16~24 |
| FR2 (TDD, 120 kHz SCS) | 171 (格式 B4) | 10 ms | 8 | 32~64 |
| FR1 (FDD, 15 kHz SCS) | 16 (格式 0) | 1 ms | 1 | 10 |

```
频率 (RB)
  ↑
  │  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐
  │  │ RO #3    │ │ RO #7    │ │ RO #11   │ │ RO #15   │  msg1-FDM=8
  │  ├──────────┤ ├──────────┤ ├──────────┤ ├──────────┤
  │  │ RO #2    │ │ RO #6    │ │ RO #10   │ │ RO #14   │

## 4. 前导序列与根序列

### 4.1 根序列索引

NR 定义了两种序列长度及对应的根序列集合:

| 序列类型 | $L_{RA}$ | 根序列范围 | 根序列总数 | 适用前导格式 |
|:---------|:--------:|:----------|:---------:|:------------|
| 长序列 | 839 | $u = 0, 1, ..., 837$ | 838 个 | Format 0/1/2/3 |
| 短序列 | 139 | $u = 0, 1, ..., 137$ | 138 个 | A1/A2/A3, B1/B2/B3/B4, C0/C2 |

每个逻辑根序列索引 $i$ 映射到物理根序列 $u$:

$$u = f(i, L_{RA})$$

其中映射由 3GPP TS 38.211 表 6.3.3.1-3 (长序列) 和 表 6.3.3.1-4 (短序列) 定义。映射设计确保相邻逻辑索引的物理根序列在互相关特性上保持低相关。

### 4.2 循环移位与零相关区配置

**循环移位 $N_{CS}$** 决定了通过移位一个根序列可生成的前导数量, 以及前导间的零相关区长度:

$$T_{ZCZ} = N_{CS} \cdot T_s \cdot \kappa$$

零相关区越宽 → 每个根序列产出的前导数越少 → 小区覆盖越大 (容忍更大时延扩展和往返时延)。

#### 非受限集 (Unrestricted Set) — 低速/小小区

| $N_{CS}$ 配置 (长序列) | 解释 | 每根前导数 | 小区半径 |
|:-----------------------:|:----|:----------:|:--------:|
| 0 | gNB 未配置, 由 zeroCorrelationZoneConfig (0..15) 指示 | — | — |
| 13 | 最小配置, 时延扩展容忍 5.2 $\mu$s | 64 | ~0.8 km |
| 26 | 中等配置 | 32 | ~1.5 km |
| 46 | 较大配置 | 18 | ~2.7 km |
| 119 | 大配置 | 7 | ~7.0 km |
| 839 | 无循环移位复用 (根序列专用) | 1 | 全部小区 |

**每根前导数**: $\lfloor L_{RA} / N_{CS} \rfloor$ (非受限集)

### 4.3 受限集 (Restricted Set A/B) — 高速场景

高速 UE 产生多普勒频移 ($f_d = v/\lambda$), 频率偏移导致 PRACH 检测时出现额外峰值 (多普勒模糊)。

| 参数 | Restricted Set A | Restricted Set B |
|:-----|:----------------:|:----------------:|
| 适用速度 | 200-350 km/h | >350 km/h (高铁) |
| 原理 | Ncs 分段, 每段附加保护区间 | Ncs 分段 + 双峰值检测 |
| 每根前导数 | 约为非受限集的 1/2 ~ 1/3 | 进一步减半 |
| 循环移位公式 | $C_v = d_{start}\lfloor v/n_{shift}^{RA} \rfloor + (v \bmod n_{shift}^{RA}) N_{CS}$ | 更复杂分段 |

**多普勒效应在 ZC 序列上的表现**:

ZC 序列的频率偏移 $\Delta f$ 在 PDP 上产生额外的相关峰, 偏移量为:

$$\Delta_{peak} = \pm (u^{-1} \bmod L_{RA}) \cdot \Delta f \cdot T_{SEQ}$$

其中 $u^{-1}$ 是根序列的模逆。当 $\Delta f = \pm 1/T_{SEQ}$ 时, 主峰移动一个完整的 ZC 序列周期 (循环移位), 产生模糊。受限集通过限制可用的循环移位范围, 让这些模糊峰落在保护区内从而被忽略。

### 4.4 前导检测原理

```
ZC 序列自相关检测:
                                          ┌──────────┐
  r(n) ──→ 与本地 ZC 共轭频域相乘 ──→ IFFT ──→ |·|² ──→ PDP (功率时延谱)
               ↑                                        ↓
         conj(FFT(x_u(n)))                          峰值检测 → TA 估计
```

PDP 上出现峰值的位置 $k$ 对应往返时延:

$$TA = k \cdot T_s \cdot \kappa$$

其中 $T_s = 1/(30.72 \text{ MHz})$ (LTE 基准), $\kappa = 64$ (NR 缩放因子)。

## 5. NR PRACH 检测处理链

### 5.1 完整处理链

```
天线接收
    │
    ▼
┌──────────────────────────────────────────────────────────┐
│  1. 时域去 CP                                             │
│     r_cp_removed(n) = r(n + N_CP),  n = 0..N_FFT-1       │
└──────────────────────────────────────────────────────────┤
    │
    ▼
┌──────────────────────────────────────────────────────────┐
│  2. N 点 FFT (N = 长格式: e.g. 24576; 短格式: 取决于 BW)  │
│     R(k) = Σ r_cp_removed(n)·e^{-j2πkn/N}                │
└──────────────────────────────────────────────────────────┤
    │
    ▼
┌──────────────────────────────────────────────────────────┐
│  3. 频域 PRACH 解映射 (PRACH 子载波抽取)                   │
│     从 R(k) 中提取 L_RA 个 PRACH 子载波                    │
│     R_prach(m) = R(k_offset + m),  m = 0..L_RA-1         │
└──────────────────────────────────────────────────────────┤
    │
    ▼
┌──────────────────────────────────────────────────────────┐
│  4. 频域匹配滤波 (与根序列共轭相乘)                         │
│     M(m) = R_prach(m) · X_u^*(m)                          │
│     其中 X_u(m) = FFT{x_u(n)} ← 本地预计算                │
└──────────────────────────────────────────────────────────┤
    │
    ▼
┌──────────────────────────────────────────────────────────┐
│  5. L_RA 点 IFFT (生成时域 PDP)                            │
│     pdp(n) = (1/L_RA)·Σ M(m)·e^{+j2πmn/L_RA}             │
└──────────────────────────────────────────────────────────┤
    │
    ▼
┌──────────────────────────────────────────────────────────┐
│  6. 功率计算                                               │
│     PDP(n) = |pdp(n)|²                                    │
└──────────────────────────────────────────────────────────┤
    │
    ▼
┌──────────────────────────────────────────────────────────┐
│  7. 峰值检测 + 门限比较                                    │
│     peak_idx, peak_val = argmax_n PDP(n),                 │
│                          s.t. PDP(n) > Thr · σ²_noise     │
└──────────────────────────────────────────────────────────┤
    │
    ▼
┌──────────────────────────────────────────────────────────┐
│  8. TA 估计                                                │
│     TA = peak_idx · T_s · κ                               │
│     量化: TA_cmd = round(TA / 16T_s) (RAR 内 12 bits)     │
└──────────────────────────────────────────────────────────┘
```

                  │                  NR PRACH 接收机                       │
                  │                                                       │
  RX Ant ──────→ │  ┌─────┐   ┌─────┐   ┌──────────┐   ┌──────────┐     │
                 │  │ CP  │   │ N点 │   │ 频域 PRACH │   │ 频域匹配  │     │
                 │  │去除 │──→│ FFT │──→│  解映射    │──→│  滤波     │     │
                 │  └─────┘   └─────┘   │ (L_RA点)  │   │ M=R×X^*   │     │
                 │                      └──────────┘   └──────────┘     │
                 │                                                    │     │
                 │  ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌───┐│     │
  ──→ TA ────────│──│  TA估计  │←──│ 峰值检测  │←──│ PDP=|·|² │←──│   ││     │
                 │  └──────────┘   │ >门限?   │   └──────────┘   │IFFT││     │
                 │                 └──────────┘                   └───┘│     │
                 └───────────────────────────────────────────────────────┘
                                   ↑ 多天线: 各天线分别处理后合并 PDP
```

### 5.3 检测门限

PRACH 检测本质上是二元假设检验:

| 假设 | 含义 | 统计特性 |
|:-----|:----|:---------|
| $H_0$ | 仅噪声 (无 PRACH 传输) | PDP 为纯噪声, 峰值服从瑞利/指数分布 |
| $H_1$ | 信号 + 噪声 (有 PRACH 传输) | PDP 存在相关峰 + 噪声基底 |

**门限设计**:

| 门限类型 | 公式 | 虚警概率 | 检测概率 |
|:---------|:----|:--------:|:--------:|
| 固定门限 | $Thr_{fixed}$ | 低 (已知噪声环境) | 低 (干扰变化时) |
| 自适应门限 (噪声归一化) | $Thr = \alpha \cdot \bar{P}_{noise}$ | 可控 (< 0.1%) | 高 |
| CFAR 门限 (Cell-Averaging) | $Thr(k) = \beta \cdot \frac{1}{N_{ref}} \sum_{n \in ref} PDP(n)$ | 理论可控 | 高 (鲁棒) |

**典型参数**:

| 参数 | 典型值 | 说明 |
|:-----|:------:|:-----|
| $\alpha$ (噪声门限系数) | 4~8 (折合 6~9 dB) | 高于噪声中值 4-8 倍 |
| $P_{FA}$ 目标 | 0.1% (每波束) | NR 规范建议 |
| $P_D$ 目标 | >99% @ SNR=-10dB | 对应 3GPP RAN4 要求 |
| 天线增益 | 天线数 N → 10log10(N) dB | 多天线合并提升 SNR |

### 5.4 多天线 PRACH 接收

```
天线 0 → [处理链] → PDP_0 ─┐
天线 1 → [处理链] → PDP_1 ─┤
   ...                      ├→ 非相干合并: PDP_comb(n) = Σ PDP_i(n)
天线 N → [处理链] → PDP_N ─┘          ↓
                                 峰值检测 → TA
```

| 合并方式 | 公式 | 增益 | 注意 |
|:---------|:----|:----:|:-----|
| 非相干合并 | $PDP_{comb} = \sum |pdp_i|^2$ | ~$3\sqrt{N}$ | 不需要相位对齐, FPGA 实现简单 |
| 相干合并 | $pdp_{comb} = |\sum pdp_i|^2$ | $N$ (理想) | 需要跨天线相位校正, BF 权值已知时可用 |

## 6. PRACH 功率控制

### 6.1 PRACH 发送功率公式

UE 第一次 PRACH 发送功率由下式确定 (TS 38.213 §8.1):

$$P_{PRACH}(i) = \min\{P_{CMAX}(i), \text{preambleReceivedTargetPower} + PL\}$$

其中:

| 参数 | 名称 | 来源 | 范围 |
|:-----|:-----|:-----|:-----|
| $P_{CMAX}$ | UE 最大发射功率 | UE 自身能力 | e.g. +23 dBm (Power Class 3) |
| preambleReceivedTargetPower | gNB 目标接收功率 | RRC: `preambleReceivedTargetPower` | -202 ~ -60 dBm |
| $PL$ | 下行路损估计 | UE 根据 SSB 测量 | UE 计算: `referenceSignalPower - RSRP` |

重发时的功率公式 (含功率爬坡):

$$P_{PRACH}(i) = \min\{P_{CMAX}(i), \text{preambleReceivedTargetPower} + PL + \Delta_{preamble} + (N_{preamble} - 1) \cdot \text{powerRampingStep}\}$$

| 新增参数 | 含义 | 来源 |
|:---------|:-----|:-----|
| $\Delta_{preamble}$ | 格式相关的功率偏置 | TS 38.213 表 8.1-1 |
| $N_{preamble}$ | 前导发送计数器 (从 1 起) | UE 本地计数 |
| powerRampingStep | 每次重发的功率增量 | RRC: `powerRampingStep` = {0, 2, 4, 6} dB |

### 6.2 格式相关的功率偏置 $\Delta_{preamble}$

不同 PRACH 格式因序列长度和重复次数不同, 接收机处理增益不同, 需要的发送功率也不同:

| 前导格式 | $\Delta_{preamble}$ (dB) | 处理增益基准 |
|:---------|:------------------------:|:------------|
| 0 | 0 | 基准 (L_RA=839, 无重复) |
| 1 | 0 | 基准 |
| 2 | -3 | 序列长度翻倍 (+3dB 增益) |
| 3 | -3 | 序列长度翻倍 |
| A1 | 8 | 短序列 (L_RA=139, -7.8dB + 其他因素) |
| A2 | 5 | — |
| A3 | 3 | — |
| B1 | 8 | — |
| B2 | 5 | — |
| B3 | 3 | — |
| B4 | 0 | 12×重复补偿 (+10.8dB) |
| C0 | 5 | — |
| C2 | 0 | 2×重复 + 2×序列长度 |

### 6.3 功率爬坡流程

```
初始发送
  N_preamble = 1
  P_TX = preambleReceivedTargetPower + PL
    │
    ▼
  发送 Msg1 ────→ 等待 RAR 窗口 (ra-ResponseWindow)
    │                │
    │           ┌────┴────┐
    │         收到RAR   超时/无RAR
    │           │         │
    │           ▼         │
    │         Msg3 →      │
    │         Msg4 → 成功  │
    │           │         │
    │           ▼         ▼
    │       接入完成    N_preamble += 1
    │                   P_TX += powerRampingStep
    │  ┌─────────────────┘
    │  │ PREAMBLE_TRANSMISSION_COUNTER < preambleTransMax?
    │  ├── 是──→ 重发
    │  └── 否──→ 物理层上报随机接入问题 (MAC 层可能触发 RLF)
```

**关键参数**:

| 参数 | RRC 字段 | 典型值 | 说明 |
|:-----|:---------|:------:|:-----|
| 最大重发次数 | `preambleTransMax` | 3, 4, 5, 6, 7, 8, 10, 20, 50, 100, 200 | 超过则上报问题 |
| 爬坡步长 | `powerRampingStep` | 2, 4 dB | 每次重发增量 |
| RAR 窗口长度 | `ra-ResponseWindow` | 1~10 个时隙 (取决于 SCS) | 超时则重发 |

### 6.4 FR2 波束扫描与功率控制

FR2 中 PRACH 与波束扫描紧密耦合:

1. UE 按 SSB 波束分组, 每组波束独立维护功率爬坡状态
2. 若当前波束的 PRACH 重发达最大次数, UE 切换波束重新开始
3. 总发送次数受 `preambleTransMax` × SSB 波束数限制

```
SSB 波束 #0 → N0 次前导发送 (功率爬坡)
   若失败
SSB 波束 #1 → N1 次前导发送 (重置功率 + 新爬坡)
   若失败
   ...
   总体超时 → MAC 上报随机接入失败
```

## 8. FPGA 实现要点

### 8.1 关键计算资源

| 模块 | 运算 | 规模 | 实现方案 |
|:-----|:----|:-----|:---------|
| 839 点 FFT/IFFT | 非 2 幂次 FFT | 839 点 | PFA (Prime Factor Algorithm) 或 WFTA |
| 139 点 FFT/IFFT | 小素数 FFT | 139 点 | 直接 DFT 或 PFA |
| 频域匹配滤波 | 复数乘法 | $L_{RA}$ 点/根序列 | 并行乘加 + 流水线 |
| PDP 峰值搜索 | 比较器树 | $L_{RA}$ 个样本 | 并行比较 + 分级归约 |
| 噪声功率估计 | 统计 | 滑动窗 | 自适应门限计算 |

### 8.2 多根序列并行检测

gNB 需同时检测多个根序列 (覆盖 64 个前导)。实现策略:

```
方案 A (时域共享): 复用同一 FFT + 匹配滤波器, 分时轮询根序列
  资源: 1×FFT + 1×MF, 时延: T_frame × N_corr

方案 B (频域并行): 多个 MF 并行, 共用 FFT 输出
  资源: 1×FFT + K×MF + K×IFFT, 时延: T_frame
  K = 需并行检测的根序列数
```

产线常用方案 B, $K=4~8$ 的并行度即可覆盖典型场景。

### 8.3 长/短序列双模支持

现代 NR PRACH 接收机需同时支持长序列和短序列:

```
配置寄存器
  ├── L_RA_SEL: 839 / 139
  ├── FORMAT: 0/1/2/3 / A1/A2/A3 / B1/B2/B3/B4 / C0/C2
  ├── msg1-FDM
  └── zeroCorrelationZoneConfig
          ↓
   参数计算 → FFT 尺寸选择 → 匹配滤波器配置 → 门限加载
```
