# MATLAB 代码约束

## 一、文件组织

### 1.1 目录结构
- 函数文件放入 `07_mat/00_fx/`
- 配置常量文件放入 `07_mat/01_conf/`
- 模型和计算脚本放入 `07_mat/02_script/`
- 每个文件只包含一个主函数（与文件名相同）

### 1.2 文件命名
- 函数名与文件名保持一致（MATLAB 强制要求）
- 配置常量文件以 `config_` 开头，如 `config_fft_params.m`
- 脚本文件以动词开头，如 `plot_waveform.m`、`calc_snr.m`

---

## 二、命名规范

### 2.1 变量命名
| 类别 | 规范 | 示例 |
|------|------|------|
| 变量 | 小驼峰，名词 | `dataLength`、`sampleRate` |
| 常量 | 全大写 + 下划线 | `FS_HZ`、`FFT_SIZE` |
| 结构体字段 | 小驼峰 | `signal.amplitude` |
| 循环索引 | `i`、`j`、`k` | — |
| 布尔变量 | 以 `is`/`has`/`enable` 开头 | `isValid`、`enableFilter` |

### 2.2 函数命名
| 类别 | 规范 | 示例 |
|------|------|------|
| 主函数 | 与文件名一致 | `function calc_fft(...)` |
| 辅助函数 | 以动词开头 | `function validate_input(...)` |
| 绘图函数 | 以 `plot_` 开头 | `function plot_spectrum(...)` |

---

## 三、代码风格

### 3.1 格式要求
- 缩进：4 个空格（不使用制表符）
- 行宽：不超过 100 字符
- 运算符两侧加空格：`a + b` 而非 `a+b`
- 逗号后加空格：`func(a, b, c)` 而非 `func(a,b,c)`
- 分号结尾：除需要显示结果的调试外，所有语句以 `;` 结尾

### 3.2 注释规范
- 每个函数文件头部必须有注释块，说明功能、输入、输出
- 关键算法步骤必须有行注释
- 复杂计算公式旁标注公式来源或物理意义
- 使用 `%%` 分节组织长脚本

---

## 四、函数设计

### 4.1 函数结构
```
function [out1, out2] = func_name(in1, in2)
% FUNC_NAME - 功能简要描述
% 输入：
%   in1 - 说明
%   in2 - 说明
% 输出：
%   out1 - 说明
%   out2 - 说明

    % 输入校验
    validateattributes(...)

    % 主体计算

    % 输出赋值
end
```

### 4.2 函数规范
- 函数长度不超过 100 行（超过时考虑拆分子函数）
- 必须包含输入参数校验（使用 `validateattributes` 或 `narginchk`）
- 输出参数必须始终有明确的赋值路径
- 禁止在函数内部使用 `clear all` 或 `clc`
- 避免使用 `eval`、`feval`，优先使用函数句柄

---

## 五、编码注意事项

### 5.1 性能相关
- 循环中预分配数组（使用 `zeros`、`ones` 预分配），避免动态扩容
- 优先使用向量化操作代替 `for` 循环
- 避免在循环内调用 `size()`，在循环前一次性获取
- 大量数据使用列优先存储（MATLAB 默认）

### 5.2 精度相关
- 比较浮点数时不用 `==`，用 `abs(a - b) < eps` 或容差值
- FPGA 算法建模时明确数据类型（定点数用 `fi` 对象）
- FFT 等运算注意归一化处理

### 5.3 脚本 vs 函数
- 算法模块必须写成函数，不能是脚本
- 顶层验证/可视化可用脚本
- 脚本中调用 `clear` 时使用 `clear variables` 而非 `clear all`

---

## 六、Simulink 约束（如使用）

- 模型中所有信号必须有明确的数据类型
- 使用 `assert` 模块做信号范围检查
- 模型参数从 MATLAB 工作区或 `config_` 文件读取，禁止硬编码

---

## 七、版本管理

- `.asv`（自动保存文件）不提交，已在 .gitignore 中
- `slprj/`（Simulink 构建产物）不提交
- 仿真生成的数据文件（`.mat` 工作区保存）不提交
- 配置参数文件（`config_*.m`）可以提交

---

## 八、代码检查

- 提交前运行 `checkcode('<file>.m')`，确保零错误
- 手动运行：
```
matlab -batch "checkcode('<file>.m'); exit;"
```
- 常见 checkcode 警告应清零：
  - 未使用的变量/输出
  - 未预分配的变量
  - 在循环内大小改变的变量
