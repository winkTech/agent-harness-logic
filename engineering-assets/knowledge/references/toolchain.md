## 二、FPGA 开发工具

### 2.1 综合工具（主开发工具）
| 项目 | 内容 |
|------|------|
| 用途 | FPGA 综合、布局布线、时序分析、比特流生成 |
| 安装路径 | `<FPGA_TOOL_INSTALL_DIR>` |
| 工程文件 | 视工具而定（如 `.tdprj`、`.xpr`、`.qpf`） |
| 约束文件 | 视工具而定（如 `.adc`、`.xdc`、`.sdc`） |
| 调试工具 | 视工具而定（如 TDLA、ILA、SignalTap） |

- 约束文件格式以实际工具为准
- 片内调试工具用于实时信号抓取

### 2.2 逻辑仿真工具
| 项目 | 内容 |
|------|------|
| 用途 | RTL 仿真、功能验证、时序仿真 |
| 安装路径 | `<SIMULATOR_INSTALL_DIR>` |
| 编译命令 | 视工具而定（如 `vlog` / `vcom` / `xvhdl` / `ghdl`） |
| 仿真命令 | 视工具而定（如 `vsim` / `xsim` / `ghdl`） |

- 通常支持 `-lint` 参数做代码语法检查
- 支持批处理模式（如 `vsim -c -do run.do`）
- 仿真产物（波形文件、编译库、日志）不应提交到 git

## 三、算法与数据处理工具

### 3.1 MATLAB
| 项目 | 内容 |
|------|------|
| 用途 | 数学建模、算法验证、信号处理、数据可视化 |
| 安装路径 | `<MATLAB_INSTALL_DIR>` |
| 命令行 | `matlab -batch "command"` |
| 代码分析 | `checkcode('<file>.m')` |

- 启动较慢，批处理模式适合自动化检查

### 3.2 Python
| 项目 | 内容 |
|------|------|
| 用途 | 脚本自动化、数据处理、测试辅助 |
| 安装路径 | 视系统环境而定 |
| Linter（推荐） | `ruff`（快速，Rust 实现）或 `flake8`（稳定成熟） |
| 安装 linter | `pip install ruff` 或 `pip install flake8` |

- 在 Windows 系统上注意区分系统 `python` 与微软商店重定向
