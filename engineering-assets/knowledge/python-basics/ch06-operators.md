# Python 常见运算

## 算术运算符
| 运算符 | 说明 | 示例 |
|--------|------|------|
| `+` | 加法 / 字符串拼接 | `2 + 3` → `5`；`"A"+"B"` → `"AB"` |
| `-` | 减法 | `5 - 3` → `2` |
| `*` | 乘法 / 字符串重复 | `3 * 4` → `12`；`"A"*3` → `"AAA"` |
| `/` | 除法（结果必为 float） | `5 / 2` → `2.5` |
| `//` | 整数除法 | `5 // 2` → `2` |
| `%` | 取模（余数） | `10 % 3` → `1` |
| `**` | 乘幂 | `2**3` → `8` |

> **NumPy 矩阵乘法**用 `@` 运算符，不是 `*`。

## 比较运算符
| 运算符 | 说明 |
|--------|------|
| `==` | 等于 |
| `!=` | 不等于 |
| `>` / `<` | 大于 / 小于 |
| `>=` / `<=` | 大于等于 / 小于等于 |

## 逻辑运算符
| 运算符 | 说明 | 示例 |
|--------|------|------|
| `and` | 与（全真才真） | `True and False` → `False` |
| `or` | 或（一真即真） | `True or False` → `True` |
| `not` | 非（取反） | `not True` → `False` |

## 赋值运算符
```python
x = 10       # 基本赋值
x += 1       # x = x + 1
x -= 1       # x = x - 1
x *= 2       # x = x * 2
x /= 2       # x = x / 2
```

## 成员运算符
```python
"a" in "apple"     # → True
"b" not in "apple" # → True
```

## 身份运算符
```python
x is y      # 是否引用同一个对象
x is not y  # 是否引用不同对象
# 区别于 ==（比较值是否相等）
```

## 转义字符
| 序列 | 说明 |
|------|------|
| `\n` | 换行 |
| `\t` | 制表符 |
| `\\` | 反斜杠本身 |
| `\'` | 单引号 |
| `\"` | 双引号 |

## 优先级
括号 `()` > 幂 `**` > 乘除 `*/` > 加减 `+-`  
建议用括号明确优先级，增强可读性。
