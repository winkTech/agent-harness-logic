# 数系与基础代数

## 数系层级
```
ℕ 自然数 {0, 1, 2, ...}
  ↓ 加逆元
ℤ 整数 {..., -2, -1, 0, 1, 2, ...}
  ↓ 乘逆元
ℚ 有理数 {p/q | p, q ∈ ℤ, q ≠ 0}
  ↓ 完备化
ℝ 实数（有理数 + 无理数）
  ↓ 代数闭包
ℂ 复数 {a + bi | a, b ∈ ℝ, i² = -1}
```

## 基础代数
- **交换律**: a + b = b + a, a × b = b × a
- **结合律**: (a + b) + c = a + (b + c), (a × b) × c = a × (b × c)
- **分配律**: a × (b + c) = a × b + a × c
- **等式的性质**: 两边同加减乘除（除数不为0）等式仍成立
- **乘法公式**: (a+b)² = a²+2ab+b², (a-b)² = a²-2ab+b², (a+b)(a-b) = a²-b²

## 计数法
- **科学记数法**: 8.8 × 10³ = 8800, 8.8 × 10⁻³ = 0.0088
- **有效数字**: 3.14 (3位有效数字), 0.00314 (3位有效数字)
