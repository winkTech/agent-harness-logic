# 圆锥曲线

圆锥曲线是平面与圆锥面相交所得的曲线，包括椭圆、抛物线和双曲线。

## 标准方程

### 抛物线 (Parabola)
- **开口向右**: y² = 4ax
- **焦点**: (a, 0), **准线**: x = -a
- **开口向上**: x² = 4ay, **焦点**: (0, a), **准线**: y = -a
- 离心率 e = 1

### 椭圆 (Ellipse)
- **标准形**: x²/a² + y²/b² = 1 (a ≥ b > 0)
- **焦点**: (±c, 0), c² = a² - b²
- **离心率**: e = c/a < 1
- **面积**: S = πab

### 双曲线 (Hyperbola)
- **标准形**: x²/a² - y²/b² = 1
- **焦点**: (±c, 0), c² = a² + b²
- **离心率**: e = c/a > 1
- **渐近线**: y = ±(b/a)x

## 统一的二次型形式
Ax² + Bxy + Cy² + Dx + Ey + F = 0

判别式 Δ = B² - 4AC:
- Δ < 0: 椭圆（包括圆）
- Δ = 0: 抛物线
- Δ > 0: 双曲线
