# sync_top — 已知限制（0.2.0, ADR-003 契约）

以下各条来自实测与设计裁决，非推测；验证证据见 README「验证现状」。

1. **无反压契约**（ADR-003 裁决③）：同步前端是实时采样流，`m_axis_tready`
   被忽略；稳态运行中下游必须恒 ready，瞬时拒收丢样点属上游集成责任。
   需要弹性的集成方在下游自接已认证的 `axis_skid_buffer`。
2. **因果校正的常数相位偏置**：校正相位参考零于 `corr_start`，CFO 在
   [0, corr_start) 累积的相位作为**常数旋转**留在输出流中（下游信道
   估计/均衡自然吸收，如 channel_est_top 的 H_LTS）。与 golden 旧离线
   批改语义不同（该语义已随 ADR-003 作废）。
3. **直通段非严格恒等**：估计锁存前样点走 θ=0 旋转流水，输出 ≈ 输入
   ±8 LSB（K 预缩放 + 14 级 CORDIC 逐级截断，实测 ~6 LSB）。
4. **T1 前段部分未校正**（因果结构性）：`corr_start = plat_end + 40` 落于
   GI2/T1 边界附近，T1 头部数样点可能未校正；由 T2 防错锁保证定时不错锁
   （判据 `|R(pk-64)|² ≥ |R(pk)|²/4`）。若信道使平顶大幅后延（plat_end >
   T1S-40），防错锁裕量收窄——验收包络为 AWGN SNR ≥ 10dB 量级、|ε| ≤ 0.5。
5. **单突发语义**：`o_sync_locked` 置位保持到复位；不支持不复位连续
   多包重同步（重新武装需 `i_rst`）。
6. **固定延迟 384 拍**：m_axis 相对 s_axis 恒延迟 P_DLY=384 拍（BRAM
   对齐延迟线），流前 384 样点无输出。
7. **符号量化相关器**（ADR-003 裁决②）：T1 系数量化 ±1（值恰为 0 的
   4 个分量取 -1），峰旁比 ≈3.5（全精度参考实测同峰位）；系数表须与
   golden 导出表一致（cosim 逐位核对）。
8. **检测动态范围**：判决用 `>>16` 截断后平方，输入幅度 ≲0.05 时判决
   精度下降；验收包络内（前导码 ~0.1-0.23 满幅）裕量充足。
9. **UVM 环境断链**（承自 0.1.0）：`tb/uvm/` 相对 include 路径断链且
   依赖旧语义向量，按原样不可编译；判卷由定向 TB + cosim 承担。
10. **粗 CFO 估计范围**：|ε| < 2（角度 |φ|<π/2 的反演范围）；802.11a
    残余 CFO 规格远小于此。精 CFO（T1/T2 相位差）不在 RTL 范围
    （golden 向量即用粗校正流，ADR-003）。
