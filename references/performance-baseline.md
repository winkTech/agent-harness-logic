## 性能目标

### 启动性能

| 指标 | 目标 | 说明 |
|------|------|------|
| **启动时间** | < 5 秒 | 从启动到可交互 |
| **Token 消耗** | < 1500 | 启动时消耗的 token |

### 响应性能

| 指标 | 目标 | 说明 |
|------|------|------|
| **首 token 延迟** | < 2 秒 | 发送消息到开始响应 |
| **输出速度** | > 30 token/s | 响应输出速度 |

### 知识检索

| 指标 | 目标 | 说明 |
|------|------|------|
| **检索准确率** | > 90% | 检索结果与需求匹配 |
| **检索速度** | < 1 秒 | 从查询到返回结果 |

## 监控方法

### 手动监控

```bash
# 运行性能监控脚本
bash ~/.claude/scripts/perf-monitor.sh
```

### 自动监控

```bash
# 添加到 crontab（可选）
0 */6 * * * bash ~/.claude/scripts/perf-monitor.sh >> ~/.claude/logs/perf.log
```
