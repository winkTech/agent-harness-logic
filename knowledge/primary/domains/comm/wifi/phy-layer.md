## 1. PHY 层总体架构

```
MAC ─── 发送流程 ──→
  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐
  │ 加扰     │→ │ 编码     │→ │ 交织     │→ │ 星座映射 │→ │ 导频插入 │
  │ (数据白化)│  │ (BCC/LDPC)│  │ (频域排列) │  │ (QAM调制) │  │ (导频符号)│
  └──────────┘  └──────────┘  └──────────┘  └──────────┘  └──────────┘

  ┌──────────┐  ┌──────────┐  ┌──────────┐
→ │ 子载波映射│→ │ IFFT    │→ │ 加 GI   │  ─→ RF (OFDM 符号)
  │ (资源分配)│  │ OFDM调制│  │ (CP插入) │
  └──────────┘  └──────────┘  └──────────┘
```

## 2. Preamble 结构

### 2.1 通用 PPDU 帧格式

```
802.11 物理层汇聚协议 (PLCP) 给 MAC 帧添加前导码和头部:

┌─────────────────────────────────────────────────────────────────┐
│     Preamble     │      Header       │        PSDU               │
│ (前导码, 同步)  │ (SIG 字段, 信号)  │    (MAC 帧数据)             │
└─────────────────────────────────────────────────────────────────┘
```

### 2.2 各代 Preamble 演进

```
802.11a/g (non-HT):
  L-STF ─ L-LTF ─ L-SIG ─ Data (OFDM 符号)

802.11n (HT-mixed):
  L-STF ─ L-LTF ─ L-SIG ─ HT-SIG ─ HT-STF ─ HT-LTF(s) ─ Data

802.11ac (VHT):
  L-STF ─ L-LTF ─ L-SIG ─ VHT-SIG-A ─ VHT-STF ─ VHT-LTF(s) ─ VHT-SIG-B ─ Data

802.11ax (HE):
  L-STF ─ L-LTF ─ L-SIG ─ RL-SIG ─ HE-SIG-A ─ HE-STF ─ HE-LTF(s) ─ HE-SIG-B ─ Data

802.11be (EHT):
  L-STF ─ L-LTF ─ L-SIG ─ RL-SIG ─ EHT-SIG-A ─ EHT-STF ─ EHT-LTF(s) ─ Data
```

### 2.3 Legacy Preamble 字段 (所有代兼容)

| 字段 | 时间 | 说明 |
|:----|:----:|:-----|
| **L-STF** (Legacy Short Training Field) | 8 μs | 10 个重复短序列，用于粗同步/AGC/频偏估计 |
| **L-LTF** (Legacy Long Training Field) | 8 μs | 2 个重复长序列，用于精细同步/信道估计 |
| **L-SIG** (Legacy Signal) | 4 μs | 1 个 OFDM 符号 (BPSK 1/2), 指示 data 长度/速率 |

> **Legacy 兼容**: 所有 802.11a/g/n/ac/ax/be PPDU 都以 L-STF/L-LTF/L-SIG 开头，保证旧 STA 能正确解析时长字段并推迟发送 (NAV 设置)。

### 2.4 HT/VHT/HE/EHT 特有字段

| 字段 | 代 | 长度 | 内容 |
|:----|:--:|:----:|:-----|
| **HT-SIG** | n | 8 μs | MCS、BW、STBC、短 GI、编码类型 (BCC/LDPC) |
| **HT-STF** | n | 4 μs | MIMO AGC 校准 |
| **HT-LTF** | n | 4 μs × N_stream | MIMO 信道估计，每流 1 个 LTF |
| **VHT-SIG-A** | ac | 8 μs | BW、NSTS、GI、编码、MCS (2 OFDM 符号) |
| **VHT-STF** | ac | 4 μs | MU-MIMO AGC |
| **VHT-LTF** | ac | 4 μs × N_stream | 每用户每流独立 LTF |
| **VHT-SIG-B** | ac | 4 μs | 每用户流数指示 (MU 场景) |
| **RL-SIG** | ax/be | 4 μs | L-SIG 重复 (用于 HE/EHT 检测) |
| **HE-SIG-A** | ax | 8 μs | 带宽、GI+LTF、编码、MCS、DCM |
| **HE-SIG-B** | ax | 可变 (8+ μs) | RU 分配、每用户 MCS (OFDMA 场景) |
| **EHT-SIG-A** | be | 8 μs | 带宽、GI+LTF、编码、MCS |

## 3. 编码方案

### 3.1 编码演进

| 标准 | 强制码 | 可选码 | 码率 |
|:----|:------|:------|:----:|
| 802.11a/g | BCC | — | 1/2, 2/3, 3/4, 5/6 |
| 802.11n (HT) | BCC | BCC | 1/2, 2/3, 3/4, 5/6 |
| 802.11ac (VHT) | BCC | BCC+LDPC | 1/2, 2/3, 3/4, 5/6 |
| 802.11ax (HE) | BCC | BCC+LDPC | 1/2, 2/3, 3/4, 5/6 (LDPC: 1/2, 2/3, 3/4, 5/6) |
| 802.11be (EHT) | LDPC | LDPC+BCC | 1/2, 2/3, 3/4, 5/6 |

> **趋势**: 802.11be 反转 — LDPC 成为强制，BCC 降为可选。

### 3.2 BCC (二进制卷积编码)

```
编码器: 码率 1/2, 约束长度 K=7, 生成多项式 g0=133_o, g1=171_o
         ┌─────────┐
  input ─┤ K=7 CC  ├─── A: X = g0 (133_o)  ── 并串
         │ 1/2     ├─── B: Y = g1 (171_o)  ── 转换
         └─────────┘

打孔实现更高码率:
  码率 2/3:  A B  →  A B (删除 B 每 2 位)
  码率 3/4:  A B  →  A B (按 0110 模板删除)
  码率 5/6:  A B  →  A B (按 110101 模板删除)
```

**交织**: 块交织器 + 频率旋转 (802.11n/ac 增加每流循环移位)

### 3.3 LDPC (低密度奇偶校验码)

WiFi 使用 **QC-LDPC (准循环 LDPC)**, 与 [[../ldpc/algorithm_spec|5G NR LDPC]] 不同:

| 参数 | 802.11n/ac/ax LDPC | 5G NR LDPC |
|:----|:------------------:|:----------:|
| 提升因子 Z | 27/54/81 (3 种) | 2~384 (51 种) |
| 码长 | 648/1296/1944 bits | 灵活 |
| 最大基图 | 24 列 × 12 行 | BG1: 46×68, BG2: 42×52 |
| IR-HARQ | 否 (一次传输) | 是 (增量冗余) |
| 解码迭代 | 典型 10~20 次 | 典型 8~15 次 |

**编码矩阵规格**:

| 码率 | 基图尺寸 | Z 可选值 | 码字长度 |
|:----:|:--------:|:--------:|:--------:|
| 1/2 | 12×24 | 27, 54, 81 | 648/1296/1944 |
| 2/3 | 8×24 | 27, 54, 81 | 648/1296/1944 |
| 3/4 | 6×24 | 27, 54, 81 | 648/1296/1944 |
| 5/6 | 4×24 | 27, 54, 81 | 648/1296/1944 |

详情见: [[../ldpc/encoding_spec|LDPC 编码器规格书]]

## 4. 调制与星座映射

| 调制 | 每子载波比特 | SNR 阈值 (粗略) | 使用代 |
|:----|:-----------:|:---------------:|:------|
| BPSK | 1 | < 5 dB | 所有 (SIG 字段) |
| QPSK | 2 | ~10 dB | 所有 |
| 16QAM | 4 | ~15 dB | 所有 |
| 64QAM | 6 | ~20 dB | a/g/n/ac/ax/be |
| 256QAM | 8 | ~25 dB | ac/ax/be |
| 1024QAM | 10 | ~30 dB | ax/be |
| 4096QAM | 12 | ~35 dB | be (EHT) |

**星座标准化**:

$$NormFactor = \begin{cases}
1 & \text{BPSK} \\
1/\sqrt{2} & \text{QPSK} \\
1/\sqrt{10} & \text{16QAM} \\
1/\sqrt{42} & \text{64QAM} \\
1/\sqrt{170} & \text{256QAM} \\
1/\sqrt{682} & \text{1024QAM} \\
1/\sqrt{2730} & \text{4096QAM}
\end{cases}$$

| 参数 | 802.11a/g | 802.11n | 802.11ac | 802.11ax | 802.11be |
|:----|:---------:|:-------:|:--------:|:--------:|:--------:|
| FFT 尺寸 | 64 | 64/128 | 64/128/256/512 | 256 (≤40M) / 512 (80M) / 1024 (160M) | 同 ax |
| 数据子载波 | 48 | 52/108 | 52/108/234/468 | 234/468/980 | 同 ax |
| 导频子载波 | 4 | 4/6 | 4/6/8/16 | 同左 (HE 高导频密度) | 同 ax |
| 子载波间隔 | 312.5 kHz | 312.5 kHz | 312.5 kHz | 78.125 kHz | 78.125 kHz |
| 符号长度 | 4 μs | 4 μs | 4 μs | 12.8+GI μs | 12.8+GI μs |
| 保护间隔 (GI) | 0.8 μs | 0.4/0.8 μs | 0.4/0.8 μs | 0.8/1.6/3.2 μs | 0.8/1.6/3.2 μs |
| 最大 BW | 20 MHz | 40 MHz | 160 MHz | 160 MHz | 320 MHz |

### 5.2 802.11ax OFDMA 子载波分配

```
20 MHz RU 划分 (802.11ax/be OFDMA):
┌─────────────────────────────────────────────────────────┐
│  RU26 (26 子载波) — 最小分配单元                        │
│  RU52 (52 子载波)                                       │
│  RU106 (106 子载波)                                     │
│  RU242 (242 子载波) = 20 MHz 全带宽                     │
│  RU484 (484 子载波) = 40 MHz                            │
│  RU996 (996 子载波) = 80 MHz                            │
│  RU2×996 = 160 MHz                                      │
│  RU4×996 = 320 MHz (802.11be)                           │
└─────────────────────────────────────────────────────────┘

20MHz 示例: ┌──────────┬──────────────────────┬──────────┐
            │   直流    │    可用子载波(242)     │   边带   │
            │   DC(5)  │    ─ index -121~121    │   guard  │
            └──────────┴──────────────────────┴──────────┘
```

> OFDMA 允许将 20MHz 信道分为多个 RU (Resource Unit) 同时服务多用户。这是 802.11ax 相比 802.11ac 最大的 PHY 层变化。

## 8. FPGA 实现要点

### 8.1 LDPC 编码器 (802.11n/ac/ax)

```
结构: QC-LDPC 编码器 (双对角加速)

基图移位 → 循环移位寄存器 → 校验位累加
                              ↓
输入: Z 路并行 (Z = 27/54/81)
关键资源: Z 个循环移位器 + Z 个累加器
目标吞吐: 单流 600Mbps+ (802.11n), 多流聚合
```

### 8.2 OFDM 调制器

| 带宽 | FFT 尺寸 | 资源估算 (Xilinx FFT IP) |
|:----:|:--------:|:-----------------------:|
| 20MHz | 64 | 1 × FFT 7.1 (最小) |
| 40MHz | 128 | 1 × FFT 7.1 |
| 80MHz | 256 | 1 × FFT 9.0 |
| 160MHz | 512 | 1 × FFT 9.0 |
| 320MHz | 1024 | 1 × FFT 9.1 |

### 8.3 接收机关键模块

```
                    ┌──────────────┐
  ADC ─→ AGC ─→ 频偏估计/补偿 ─→ FFT
                   │ (L-STF 粗频偏)
                   │ (L-LTF 精频偏)
                   └──────────────┘
                           ↓
                  ┌─────────────────┐
                  │ 信道估计 (LS/MMSE) │
                  │ (L-LTF / HE-LTF)  │
                  └─────────────────┘
                           ↓
                  ┌─────────────────┐
                  │ 相位跟踪 (导频)  │ ← 每 OFDM 符号
                  └─────────────────┘
                           ↓
                  ┌─────────────────┐
                  │ 解调 → 解交织    │
                  │ → 解码 (BCC/LDPC)│
                  └─────────────────┘
```

## 9. 关键公式

**数据速率计算**:

$$R = \frac{N_{bps} \cdot R_c \cdot N_{SD} \cdot N_{SS} \cdot N_{sym}}{T_{sym} \cdot \text{聚合开销}}$$

其中 $N_{bps}$ = 每子载波比特数, $R_c$ = 编码码率, $N_{SD}$ = 数据子载波数, $N_{SS}$ = 空间流数, $T_{sym}$ = OFDM 符号时间

**Preamble 接收时长**:

$$T_{preamble} = T_{L-STF} + T_{L-LTF} + T_{L-SIG} + T_{RL-SIG} + T_{SIG-A} + T_{STF} + N_{LTF} \cdot T_{LTF} + T_{SIG-B}$$

各代 preamble 时长约 36~68 μs (不含 SIG-B 可变部分)。
