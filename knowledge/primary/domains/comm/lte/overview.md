## 1. 网络架构

### 1.1 整体架构 (SAE/LTE)

```
UE ── eNB ── S-GW ── P-GW ── 外部网络
       │
      MME
```

| 网元 | 功能 | 接口 |
|:----|:----|:----|
| **UE** | 用户终端 | Uu (空中接口) |
| **eNB** | 基站，调度中心 | X2 (eNB间), S1 (核心网) |
| **MME** | 移动性管理、鉴权 | S1-MME |
| **S-GW** | 用户面数据网关 | S1-U |
| **P-GW** | PDN 网关、IP分配 | SGi |

### 1.2 协议栈 — 用户面

```
┌──────────────────┐
│    Application   │
├──────────────────┤
│    PDCP          │  加密、完整性保护、头压缩
├──────────────────┤
│    RLC           │  分段/重组、ARQ 重传
├──────────────────┤
│    MAC           │  调度、HARQ、多路复用
├──────────────────┤
│    PHY           │  物理层 (OFDMA/SC-FDMA)
└──────────────────┘
```

### 1.3 协议栈 — 控制面

```
┌──────────────────┐
│    NAS           │  会话管理、鉴权 (UE ↔ MME)
├──────────────────┤
│    RRC           │  连接管理、移动性 (UE ↔ eNB)
├──────────────────┤
│    PDCP/RLC/MAC  │  同用户面
├──────────────────┤
│    PHY           │  物理层
└──────────────────┘
```

## 2. 帧结构 (FDD)

### 2.1 无线帧

```
1 无线帧 = 10 ms
├── 子帧 #0 (1ms) ── 子帧 #1 ── ... ── 子帧 #9
│   └── 时隙 #0 (0.5ms) ── 时隙 #1 (0.5ms)
│       └── 7个 OFDM 符号 (常规 CP)
│       └── 6个 OFDM 符号 (扩展 CP)
```

- **帧长**: 10ms，10 个子帧
- **子帧**: 1ms（1 TTI = 1 子帧）
- **时隙**: 0.5ms，常规 CP 含 7 个符号
- **扩展 CP**: 每时隙 6 个符号，用于大覆盖/多径场景

### 2.2 资源网格

```
一个时隙
┌────┬────┬────┬────┬────┬────┬────┐
│ R0 │    │    │ R0 │    │    │    │  ── 子载波 0
├────┼────┼────┼────┼────┼────┼────┤
│ R1 │    │    │    │    │ R1 │    │  ── 子载波 1
├────┼────┼────┼────┼────┼────┼────┤
│    │    │    │    │    │    │    │
├────┼────┼────┼────┼────┼────┼────┤
│ R2 │    │    │    │    │    │ R2 │  ── 子载波 N-1
└────┴────┴────┴────┴────┴────┴────┘
  符号 0                                符号 6
  R = 参考信号 (RS), 位置取决于 CRS 端口
```

| 参数 | 值 |
|:----|:----|
| 子载波间隔 Δf | 15 kHz |
| 常规 CP 长度 | 符号0: 160 Ts (~5.21μs), 符号1-6: 144 Ts (~4.69μs) |
| 采样率 (20MHz) | 30.72 MHz (Fs = 2048 × 15kHz) |
| FFT 点数 | 2048 (20MHz BW) |
| RE 数/RB | 12 子载波 × 7 符号 = 84 RE (常规 CP) |

## 4. 物理信道分类

### 4.1 下行

| 信道 | 名称 | 功能 | 调制方式 |
|:----|:----|:----|:--------|
| **PBCH** | 物理广播信道 | MIB 主信息块 | QPSK |
| **PDCCH** | 物理下行控制信道 | DCI 调度信息 | QPSK |
| **PCFICH** | 物理控制格式指示信道 | CFI 控制区域大小 | QPSK |
| **PHICH** | 物理混合ARQ指示信道 | HARQ ACK/NACK | BPSK |
| **PDSCH** | 物理下行共享信道 | 用户数据 | QPSK/16QAM/64QAM/256QAM |
| **PMCH** | 物理多播信道 | MBMS 多播 | QPSK/16QAM/64QAM |

### 4.2 上行

| 信道 | 名称 | 功能 | 调制方式 |
|:----|:----|:----|:--------|
| **PRACH** | 物理随机接入信道 | 随机接入前导 | ZC 序列 |
| **PUCCH** | 物理上行控制信道 | UCI/UCI+数据 | BPSK/QPSK |
| **PUSCH** | 物理上行共享信道 | 用户数据+UCI | QPSK/16QAM/64QAM/256QAM |
| **DMRS** | 解调参考信号 | 信道估计 | — |
| **SRS** | 探测参考信号 | 上行信道质量 | — |

## 5. 调制与编码

### 5.1 调制阶数

| 调制方式 | 每符号比特 | SINR 阈值 (近似) |
|:---------|:---------:|:---------------:|
| QPSK | 2 | < 10 dB |
| 16QAM | 4 | 10~17 dB |
| 64QAM | 6 | 17~22 dB |
| 256QAM | 8 | > 22 dB (LTE-A) |

### 5.2 信道编码

| 信道 | 编码方式 | 码率范围 |
|:----|:---------|:--------:|
| PDSCH/PUSCH (数据) | Turbo 编码 | 1/3 ~ 1 (打孔) |
| PDCCH/PCFICH/PHICH | 卷积编码 (CC) | 1/3 |
| PBCH | 卷积编码 (CC) | 1/3 |
| BCH/TCH 传输块 | CRC24A | — |
| DCI/UCI (小) | CRC16 | — |

### 5.3 速率匹配

Turbo 编码速率匹配 = **循环缓存 + 比特选择**:
1. Turbo 1/3 编码 → 3 路输出 (系统位 + 2 路校验)
2. 循环缓存 → 子块交织 → 循环缓存
3. 按调度分配的 RB 数选择比特数

## 6. 参考信号

| RS 类型 | 用途 | 位置 |
|:--------|:----|:-----|
| **CRS** (Cell-specific RS) | 下行信道估计、测量 | 全带宽，每 RB 2/4 个 RE |
| **DMRS** (UE-specific RS) | PDSCH/PUSCH 解调 | 随数据分配 |
| **CSI-RS** | CSI 测量 | 稀疏，可配置 |
| **PRS** | 定位参考信号 | 定位业务 |
| **SRS** | 上行信道探测 | 末端符号 |

## 7. 多天线 (MIMO)

| 模式 | 描述 | 层数 |
|:----|:----|:----:|
| 传输分集 (TxD) | SFBC (2Tx) / FSTD (4Tx) | 1 |
| 开环空间复用 (OLSM) | 大延迟 CDD | 2~4 |
| 闭环空间复用 (CLSM) | PMI 反馈的预编码 | 2~4 |
| MU-MIMO | 多用户同时调度 | 每用户 1~2 |
| BF (波束赋形) | 基于 CRS/DMRS 的权值 | 1 |

## 8. HARQ 机制

| 属性 | 配置 |
|:----|:----|
| 进程数 | 下行 8 个 (FDD), 上行 8 个 |
| 重传类型 | 增量冗余 (IR) |
| 反馈时机 | N+4 ms (FDD) |
| 最大重传次数 | 可配置 (默认 3~5) |
| 同步/异步 | 上行同步, 下行异步自适应 |

## FPGA 实现要点

- **CRS 生成**: Gold 序列 (PRBS-31), 初始值 $c_{init}=2^{10}\cdot(7\cdot(n_s+1)+l+1)\cdot(2\cdot N_{ID}^{cell}+1)+2\cdot N_{ID}^{cell}+N_{CP}$
- **RB 映射**: 按 VRB→PRB 跳变映射表做资源映射
- **速率匹配**: 循环缓存地址计算 + 比特选择逻辑 (LTE 打孔密度高于 NR)
- **HARQ 缓存**: 软比特 LLR 缓存，需管理 8 个进程的独立缓冲区

## 与 5G NR 关键差异

| 维度 | LTE | NR |
|:----|:----|:---|
| 子载波间隔 | 固定 15kHz | 15/30/60/120kHz |
| 编码 | Turbo | LDPC (数据) + Polar (控制) |
| 帧结构 | 固定子帧 | 灵活 slot/symbol 级 |
| MIMO | 最大 4层 (CRS-based) | 最大 8层 (DMRS-based) |
| 核心网 | EPC (MME+S-GW+P-GW) | 5GC (AMF+SMF+UPF) |
