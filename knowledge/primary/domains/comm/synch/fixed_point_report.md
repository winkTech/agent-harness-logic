# OFDM 同步 定点量化分析

> 算法: 短前导码自相关 (包检测+粗CFO) + 长前导码互相关 (精定时) + T1/T2相位差 (精CFO)
> 平台: Xilinx Kintex-7 | 日期: 2026-06-02 | 版本: v1.0

---

## 1. 定点格式规划

### 1.1 各模块格式

| 模块 | 信号 | 格式 | 位宽 | 处理 |
|:----:|:----:|:----:|:----:|------|
| — | r[n] (ADC) | Q2.14 | 16-bit | AXI4-Stream 输入 |
| 包检测 | C[n] (自相关) | Q2.30 | 32-bit | 复数 MAC，16 级累加 |
| 包检测 | P[n] (能量) | Q4.28 | 32-bit | 实 MAC，16 级累加 |
| 包检测 | M[n] (判决) | Q0.15 | 16-bit | |C|² / P²，归一化 |
| 粗 CFO | C_avg (平均自相关) | Q2.30 | 32-bit | 多段平均 |
| 粗 CFO | 角度 (atan2) | Q1.15 | 16-bit | CORDIC 输出，弧度/π |
| 粗 CFO | ε_coarse | Q1.15 | 16-bit | 归一化 CFO |
| CFO 补偿 | 旋转因子 | Q1.15 | 16-bit | CORDIC 旋转 |
| CFO 补偿 | r_corr | Q2.14 | 16-bit | 补償后信号 |
| 精定时 | R[n] (互相关) | Q3.29 | 32-bit | 64 级复数 MAC |
| 精 CFO | conj(T1)·T2 | Q3.29 | 32-bit | 64 级 MAC |
| 精 CFO | ε_fine | Q1.15 | 16-bit | 归一化 CFO |

### 1.2 字长推导

**自相关累加器 (包检测)**:
- 输入 Q2.14 × Q2.14 → Q4.28
- 16 级累加 → +4 bits → Q8.28
- 取高 30 bits: Q8.28 → Q2.30 (截去低 6 bits, 舍入)

**归一化判决度量**:
- |C|²: Q2.30 × Q2.30 → Q4.60 → Q4.28 (截断)
- P²: Q4.28 × Q4.28 → Q8.56 → Q4.28
- 除法: Q4.28 / Q4.28 → Q0.15 (16-bit 近似)

**互相关 (精定时/精 CFO)**:
- 输入 Q2.14 × Q2.14 → Q4.28
- 64 级累加 → +6 bits → Q10.28
- 取高 32 bits: Q10.28 → Q3.29

## 2. 定点误差分析

### 2.1 自相关量化

| 误差源 | 每步误差 | 16 级累积 |
|:------:|:--------:|:---------:|
| 输入量化 (Q2.14) | 2⁻¹⁴/√12 | 2⁻¹⁰/√12 |
| 乘法舍入 (Q4.28) | 0.5 LSB | 2 LSB |
| 累加截位 (Q8.28) | 0.5 LSB | 0.5 LSB |

**总 SQNR**: $SQNR_{corr} \approx -10\log_{10}(10^{-86/10} + 10^{-72/10}) \approx 72\text{dB}$

### 2.2 CFO 角度量化

CORDIC 输出角度误差:
- 迭代次数: 12 (16-bit 精度)
- 角度量化: Q1.15 → 角度误差 < 2⁻¹⁵ rad ≈ 3×10⁻⁵ rad
- CFO 归一化误差: $3\times10^{-5} / (2\pi) \approx 5\times10^{-6}$
  → 可忽略

### 2.3 CFO 补偿量化

旋转后的 r_corr 舍入到 Q2.14:
- 旋转前: CORDIC 输出 Q2.30 → 旋转 → Q2.30
- 收敛舍入 → Q2.14
- SQNR 损失: < 0.1 dB

### 2.4 定点仿真验证

| 指标 | 浮点 | Q2.14 定点 | 损失 |
|:----:|:----:|:----------:|:----:|
| 包检测 M[n] 峰值 | 0.92 | 0.90 | 0.02 |
| 粗 CFO 误差 (SNR=20) | 0.008 | 0.011 | 0.003 |
| 精定时峰值位置 | n₀ | n₀ | 0 (无影响) |
| 精 CFO 误差 | 0.002 | 0.004 | 0.002 |

> 定点化对同步性能影响极小 (CFO 误差增量 < 0.005)，所有模块使用 Q2.14/Q2.30 格式充分。
