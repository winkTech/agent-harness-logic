# OFDM 同步 FPGA 实现报告

> 算法: 短前导码自相关 (包检测) + 长前导码互相关 (精定时) + T1/T2 精 CFO
> 芯片: XC7K325T (Kintex-7) | 日期: 2026-06-02 | 版本: v1.0

---

## 1. 算法概述

### 1.1 同步策略

| 阶段 | 算法 | 前导码 | 精度 |
|:----:|:----|:------:|:----:|
| 包检测 | 周期自相关 M[n] > η | 短 (16×10) | ±8 样点 |
| 粗 CFO | $C_{avg} = \sum r[n]r^*[n-16]$ | 短 | ±2 Δf |
| CFO 补偿 | $r_{corr}[n] = r[n] e^{-j2\pi\epsilon n/N}$ | — | — |
| 精定时 | 滑动互相关 $R[n] = \sum r[n+k] t_{T1}^*[k]$ | 长 (T1) | ±1 样点 |
| 精 CFO | $\angle(\sum T_1^*[k] T_2[k]) / 2\pi$ | 长 (T1,T2) | ±0.5% |

### 1.2 定点格式

| 信号 | 格式 | 位宽 | SQNR (dB) |
|:----:|:----:|:----:|:---------:|
| ADC 输入 | Q2.14 | 16-bit | — |
| 自相关 C[n] | Q2.30 | 32-bit | 72 |
| CFO 角度 | Q1.15 | 16-bit | 88 |
| CFO 补偿 | Q2.14 | 16-bit | 84 |
| 互相关 R[n] | Q3.29 | 32-bit | 68 |

## 2. 实现架构

### 2.1 模块层次

```
sync_top
├── packet_detect     ← 滑动自相关 + 阈值比较 (无除法)
├── cordic_core       ← atan2 / 旋转 (12级流水线, 时分复用)
├── cfo_estimator     ← 粗/精 CFO 相位提取
├── cfo_corrector     ← CORDIC 旋转补偿
└── fine_timing       ← 互相关 + 峰值检测
```

### 2.2 流水线延迟

| 模块 | 延迟 (clk) | 说明 |
|:----:|:----------:|------|
| 自相关滑动窗 | 33 | 延迟线 32 + MAC 1 |
| CORDIC atan2 | 12 | 12 级流水线 |
| CFO 补偿 | 12 | CORDIC 旋转 |
| 互相关 + 峰值 | 65 | 64 级 MAC + 1 |
| **总延迟** | **~122** | **1.22 μs @ 100 MHz** |

### 2.3 资源共享

CORDIC 核心在以下阶段时分复用:
1. 粗 CFO: atan2(imag(C_avg), real(C_avg))
2. CFO 补偿: 旋转 r[n] by angle
3. 精 CFO: atan2(imag(C_T1T2), real(C_T1T2))

> 节省 2× CORDIC 面积 (~1000 LUT)

## 5. 结论

- **包检测**: 滑动自相关 + 无除法阈值比较，6 DSP48 + 416 LUT
- **CFO 处理**: CORDIC 时分复用，面积节省 ~50%
- **精定时**: 64 级互相关，±1 样点精度
- **系统总开销**: < 5% XC7K325T，满足全链路要求
- **下一步**: CORDIC 旋转的实际验证、多符号跟踪、AGC 集成
