# OFDM 信道估计 (LS/MMSE) — 算法规格书

## 1. 数学原理

### 1.1 系统模型

OFDM 系统频域接收信号：

$$Y[k] = H[k] \cdot X[k] + W[k], \quad k = 0, 1, \dots, N-1$$

其中 $H[k]$ 为信道频域响应，$X[k]$ 为发送符号，$W[k]$ 为加性噪声。

**信道估计目标**：从已知导频 $X_p[k]$ 和接收 $Y_p[k]$ 恢复 $H[k]$。

### 1.2 LS 估计 (Least Squares)

LS 估计在导频位置处：

$$\hat{H}_{LS}[k_p] = \frac{Y[k_p]}{X[k_p]} = H[k_p] + \frac{W[k_p]}{X[k_p]}$$

其中 $k_p$ 为导频子载波索引。

**复杂度**：每个导频位置一次复数除法（或乘以已知导频的共轭）。

**优势**：实现极简单，无信道先验信息需求。
**劣势**：噪声敏感，无噪声抑制能力。

### 1.3 MMSE 估计 (Minimum Mean Square Error)

MMSE 估计利用信道统计信息：

$$\hat{H}_{MMSE} = R_{HH_p} (R_{H_pH_p} + \sigma_n^2 I)^{-1} \hat{H}_{LS}$$

其中 $R_{HH}$ 为信道自相关矩阵，$\sigma_n^2$ 为噪声方差。

**简化实现**（低秩近似）：

$$\hat{H}_{MMSE} \approx W \cdot \hat{H}_{LS}$$

其中 $W$ 为预先计算的 Wiener 滤波系数矩阵。

### 1.4 插值方法

导频位置估计后，需插值到所有数据子载波：

| 方法 | 复杂度 | 性能 | 适用场景 |
|------|:------:|:----:|---------|
| **线性插值** | 极低 | 可接受 | 导频密集，慢变信道 |
| **二阶插值** | 低 | 良好 | 一般场景 |
| **DFT 插值** | 中 | 优秀 | 多径信道，需 FFT |
| **Wiener 滤波** | 高 | 最优 | 已知信道统计量 |

### 1.5 信号流图

```
                    ┌─────────────────────────┐
    Y[k] (频域)     │  导频提取               │
    ───────────────►│  (subcarrier demux)     │
                    │  → LS估计 @ 导频位置    │
                    │  → 插值 (线性/Wiener)   │
                    │  → 均衡 (单抽头)         │
                    └─────────────────────────┘
                              │
                         X_hat[k] (均衡后)
```

## 2. 参数分析

### 2.1 系统参数 (基于 802.11a OFDM)

| 参数 | 值 | 说明 |
|------|----|------|
| FFT 点数 $N$ | 64 | OFDM 符号长度 |
| 数据子载波 $N_{data}$ | 48 | 承载用户数据 |
| 导频子载波 $N_{pilot}$ | 4 | 索引 {-21, -7, 7, 21} |
| DC 子载波 | 1 | 索引 0 |
| 保护子载波 | 11 | 索引 {-32..-27, 27..31} |
| 子载波间隔 $\Delta f$ | 312.5 kHz | 20MHz / 64 |
| OFDM 符号周期 | 4 $\mu$s | (64+16)/20MHz |
| 多径时延扩展 | < 0.8 $\mu$s | 室内信道 |

### 2.2 算法选择

| 算法 | 乘法器 | 是否需要 SNR | 适用场景 |
|------|:------:|:------------:|---------|
| **LS + 线性插值** | **< 10** | **否** | **默认方案，工程首选** |
| LS + DFT 插值 | ~30 | 否 | 多径严重 |
| MMSE (简化) | ~50 | 是 | 低 SNR 场景 |
| 全 MMSE | >200 | 是 | 性能基准 |

> **推荐**: LS + 线性插值（资源优先） / LS + DFT 插值（性能优先）

### 2.3 量化和定点

| 节点 | Q 格式 | 位宽 | 说明 |
|------|--------|:----:|------|
| 接收信号 Y[k] | Q2.14 | 16 | 匹配 OFDM FFT 输出 |
| LS 估计 H_p[k] | Q2.14 | 16 | 导频处信道响应 |
| 插值后 H[k] | Q2.14 | 16 | 全子载波 |
| 均衡输出 X_hat | Q2.14 | 16 | 单抽头均衡 |
| 乘法累加 | — | 32 | 中间结果 |

## 4. 参考实现

### 4.1 MATLAB 接口

```matlab
% LS estimation at pilot positions
H_pilot = Y(pilot_idx) ./ X(pilot_idx);

% Linear interpolation
H_est = interpolate_linear(H_pilot, pilot_idx, N);

% Equalization (single-tap)
X_hat = Y ./ H_est;
```
