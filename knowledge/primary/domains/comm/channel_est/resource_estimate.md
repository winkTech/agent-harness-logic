# 信道估计 (LS+插值) 资源评估

> 目标芯片: XC7K325T (Kintex-7) | 速度等级: -2
> 工具: Vivado 2024.2 | 估计方法: 结构化分析 + 参考设计对比

---

## 1. 架构概览

```
Y[63:0] (频域, after FFT)
    │
    ▼
┌─────────────────────────┐
│   Pilot 提取 + LS 估计  │  ← 仅符号选择，零逻辑
│   H_pilot = ±Y_pilot    │
└─────────┬───────────────┘
          │ (4× Q2.14 复数)
          ▼
┌─────────────────────────┐
│   线性插值引擎           │
│   ┌─ ΔH 计算 (减法器)   │
│   ├─ 斜率 = ΔH × α     │
│   └─ H = H₀ + m × slope│
└─────────┬───────────────┘
          │ (64× Q2.14 复数)
          ▼
┌─────────────────────────┐
│   AXI4-Stream 输出       │
│   H_est (64 subcarriers) │
└─────────────────────────┘
```

## 2. 模块资源分解

### 2.1 LS 估计模块

| 子模块 | DSP48 | LUT | FF | BRAM | 说明 |
|:------:|:----:|:---:|:--:|:----:|------|
| Pilot 选择 | 0 | 8 | 0 | 0 | 4:1 MUX (固定导频位置) |
| LS 乘法 | 0 | 0 | 0 | 0 | 仅符号翻转 (±1) |
| **小计** | **0** | **8** | **0** | **0** | |

### 2.2 线性插值引擎

| 子模块 | DSP48 | LUT | FF | BRAM |
|:------:|:----:|:---:|:--:|:----:|
| ΔH 减法器 (复数) | 0 | 64 | 32 | 0 |
| 乘法器 (复数×实数) | 2 | 0 | 0 | 0 |
| 累加器 (复数) | 0 | 128 | 64 | 0 |
| 控制 FSM | 0 | 48 | 32 | 0 |
| **小计** | **2** | **240** | **128** | **0** |

> 用 2 个 DSP48 实现复数 × real 乘法 (I/Q 各一个)。
> 消耗与 OFDM 系统配置相关，可以复用。

### 2.3 DFT 插值 (备选)

| 子模块 | DSP48 | LUT | FF | BRAM |
|:------:|:----:|:---:|:--:|:----:|
| IFFT 4点 | 0 | 32 | 16 | 0 |
| 时域加窗 | 0 | 16 | 0 | 0 |
| FFT 64点 | 3 | 1200 | 800 | 1 |
| **小计** | **3** | **1248** | **816** | **1** |

> FFT 64点 IP 核资源详见 [OFDM 资源评估](../ofdm/resource_estimate.md)。
> 可与 OFDM 解调 FFT 复用，不增加额外资源。

### 2.4 AXI4-Stream 接口

| 子模块 | DSP48 | LUT | FF | BRAM |
|:------:|:----:|:---:|:--:|:----:|
| 输入 FIFO | 0 | 64 | 32 | 0.5 |
| 输出寄存器 | 0 | 32 | 64 | 0 |
| **小计** | **0** | **96** | **96** | **0.5** |

## 4. 时序分析

| 路径 | 延迟 | 约束 | 裕量 |
|:----:|:----:|:----:|:----:|
| LS + 插值 (组合) | 4.2 ns | 10 ns (100 MHz) | +5.8 ns |
| 线性插值 (单步) | 1.8 ns | 10 ns | +8.2 ns |
| FFT 64点 | 64 clk @ 100 MHz | 20 MHz | 充裕 |

> 在最坏 PVT 条件下 (慢角 0.9V/85°C)，组合逻辑延迟 < 5 ns，三倍裕量。

## 5. 与 OFDM 系统的联合资源

信道估计紧密耦合在 OFDM 接收机中：

| 联合模块 | 共享资源 | 独立新增 |
|:--------:|:--------:|:--------:|
| FFT 64点 | ✅ 复用解调 FFT | 0 |
| FIFO | ✅ 用 BRAM 共享 | 0 |
| 控制 FSM | ✅ 集成到 RX 控制器 | 0 |
| 插值引擎 | — | 2 DSP48 + ~350 LUT |

**系统总开销增量: 2 DSP48 + ~350 LUT + 0.5 BRAM**

---

## 6. 结论

- **LS + 线性插值**: 资源极低 ($\ll$ 1% 芯片)，适合所有平台
- **DFT 插值**: 可复用 FFT，额外开销仅 IFFT 4点 + 时域加窗
- **2 DSP48**: 用于复数 × 实数乘法，可用 LUT 替代 (面积折衷)
- **Fmax > 200 MHz**: 时序充裕，轻松满足 100 MHz 系统时钟

### 建议方案

| 场景 | 推荐架构 | 理由 |
|:----:|:--------:|------|
| 低开销 | LS + 线性 | 0 DSP48 (LUT 实现)、~350 LUT、适合大规模 MIMO |
| 高性能 | LS + DFT | 复用 FFT、MSE 改善 3-5 dB、适合高要求链路 |
| 折衷 | LS + 线性 (DSP) | 2 DSP48 面积更小、时序更优 |
