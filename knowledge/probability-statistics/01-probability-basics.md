# 概率论基础

## 基本概念
- **随机试验**: 结果不确定但可重复的实验
- **样本空间 Ω**: 所有可能结果的集合
- **事件**: Ω 的子集
- **概率 P(A)**: 事件 A 发生的可能性度量，满足:
  1. P(A) ∈ [0,1]
  2. P(Ω) = 1
  3. 可列可加性: P(∪Aᵢ) = ∑P(Aᵢ)（互斥事件）

## 概率计算规则
- **补事件**: P(Ā) = 1 - P(A)
- **加法公式**: P(A∪B) = P(A) + P(B) - P(A∩B)
- **乘法公式**: P(A∩B) = P(A|B)P(B) = P(B|A)P(A)

## 条件概率
P(A|B) = P(A∩B)/P(B), P(B) > 0

## 全概率公式
P(A) = ∑P(A|Bᵢ)P(Bᵢ)，其中 {Bᵢ} 是 Ω 的一个划分

## 贝叶斯定理
P(Bᵢ|A) = P(A|Bᵢ)P(Bᵢ) / ∑P(A|Bⱼ)P(Bⱼ)

后验概率 = (似然 × 先验) / 证据

## 独立性
事件 A,B 独立 ⇔ P(A∩B) = P(A)P(B)
⇔ P(A|B) = P(A)

## 组合计数
- **排列**: P(n,k) = n!/(n-k)!
- **组合**: C(n,k) = n!/[k!(n-k)!]
- **乘法原理**: 做一件事分 n 步，第 i 步有 mᵢ 种方法→共有 ∏mᵢ 种方法
- **加法原理**: 做一件事有 n 类方法，第 i 类有 mᵢ 种→共有 ∑mᵢ 种方法
