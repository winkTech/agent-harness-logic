# 函数

## 基本概念
- **函数**: f: X → Y，每个输入 x 映射到唯一输出 f(x)
- **定义域 (Domain)**: 输入 x 的取值范围
- **值域 (Range)**: 输出 f(x) 的取值范围
- **单射**：不同 x → 不同 f(x)
- **满射**：每个 y 都有 x 映射到它
- **双射**：同时满足单射和满射（一一对应）

## 多项式函数
- **一次函数**: f(x) = kx + b，图像为直线
- **二次函数**: f(x) = ax² + bx + c，图像为抛物线
  - 顶点: (-b/(2a), f(-b/(2a)))
  - 判别式: Δ = b² - 4ac（Δ>0 两个实根，Δ=0 一个重根，Δ<0 无实根）
- **幂函数**: f(x) = xⁿ

## 指数与对数
- **指数**: f(x) = aˣ (a > 0, a ≠ 1)
  - 自然指数: eˣ
  - a⁰ = 1, aˣ·aʸ = aˣ⁺ʸ, (aˣ)ʸ = aˣʸ, a⁻ˣ = 1/aˣ
- **对数**: f(x) = logₐ(x) (a > 0, a ≠ 1, x > 0)
  - 自然对数: ln(x)
  - logₐ(xy) = logₐ(x) + logₐ(y)
  - logₐ(xʸ) = y·logₐ(x)
  - 换底公式: logₐ(b) = logₓ(b)/logₓ(a)

## 三角函数
| 函数 | 符号 | 周期 | 定义域 | 值域 |
|------|------|------|--------|------|
| 正弦 | sin(x) | 2π | ℝ | [-1,1] |
| 余弦 | cos(x) | 2π | ℝ | [-1,1] |
| 正切 | tan(x) = sin(x)/cos(x) | π | x ≠ π/2 + kπ | ℝ |

**基本关系**: sin²θ + cos²θ = 1

## 反三角函数
| 函数 | 含义 |
|------|------|
| arcsin(x) | sin(y) = x，y ∈ [-π/2, π/2] |
| arccos(x) | cos(y) = x，y ∈ [0, π] |
| arctan(x) | tan(y) = x，y ∈ (-π/2, π/2) |

## 其他常用函数
- **绝对值**: |x|
- **符号函数**: sgn(x)
- **取整**: floor(x) 向下取整, ceil(x) 向上取整
- **双曲函数**: sinh(x), cosh(x), tanh(x)
