# 错误恢复指南

> 常见错误及恢复策略

---

## 常见错误类型

| 错误类型 | 表现 | 恢复策略 |
|----------|------|----------|
| **网络超时** | API 调用超时 | 重试 + 指数退避 |
| **Token 限制** | 上下文过长 | /compact 或新会话 |
| **权限拒绝** | 工具调用被阻止 | 检查权限配置 |
| **文件不存在** | 路径错误 | 验证路径 + 搜索 |
| **语法错误** | 代码检查失败 | 修复后重试 |

---

## 恢复流程

### 1. 网络超时

```
症状: API 调用超时或无响应
原因: 网络不稳定或服务端负载高

恢复步骤:
1. 等待 5-10 秒
2. 重试操作
3. 若仍失败，检查网络连接
4. 使用 /compact 减少上下文
5. 若持续失败，开新会话
```

### 2. Token 限制

```
症状: 响应变慢或被截断
原因: 上下文窗口接近上限

恢复步骤:
1. 运行 /compact 压缩上下文
2. 记录当前进度到 memory/
3. 开新会话
4. 从 memory/ 恢复进度
```

### 3. 权限拒绝

```
症状: 工具调用被阻止
原因: 权限配置限制

恢复步骤:
1. 检查 settings.json 权限配置
2. 确认操作是否必要
3. 使用更安全的替代命令
4. 如需，临时调整权限
```

### 4. 文件不存在

```
症状: 无法读取或写入文件
原因: 路径错误或文件被删除

恢复步骤:
1. 验证文件路径
2. 使用 Glob 搜索文件
3. 检查文件是否在其他位置
4. 如需，创建文件
```

### 5. 语法错误

```
症状: 代码检查失败
原因: 代码不符合规范

恢复步骤:
1. 阅读错误信息
2. 定位问题代码
3. 修复后重新检查
4. 提交前验证
```

## 指数退避策略

**公式**:
```
delay = base_delay * (2 ^ retry_count)
```

**示例**:
| 重试次数 | 延迟时间 |
|----------|----------|
| 1 | 1s |
| 2 | 2s |
| 3 | 4s |
| 4 | 8s |
| 5 | 16s |

**最大重试**: 5 次
**最大延迟**: 30 秒

## 预防措施

| 措施 | 目的 |
|------|------|
| 定期 /compact | 防止上下文膨胀 |
| 保存进度到 memory/ | 防止进度丢失 |
| 验证文件路径 | 防止文件错误 |
| 代码检查前预览 | 防止语法错误 |
| 权限最小化 | 防止安全风险 |

## 紧急情况处理

**情况 1: Agent 无响应**
```
1. 等待 30 秒
2. 按 Ctrl+C 中断
3. 开新会话
4. 从 memory/ 恢复
```

**情况 2: 数据丢失**
```
1. 检查 memory/ 记录
2. 检查 git 历史
3. 检查备份文件
4. 从最近状态恢复
```

**情况 3: 配置损坏**
```
1. 检查 settings.json 语法
2. 恢复默认配置
3. 逐步重新配置
4. 测试每个功能
```

## FPGA 特定错误

### 1. Vivado 综合失败

**症状**: 综合报错，无法生成网表

**常见原因**:
- 语法错误
- 未定义的信号
- 不完整的敏感列表
- 锁存器推断

**恢复步骤**:
```
1. 阅读综合报告中的错误信息
2. 定位问题代码（文件名 + 行号）
3. 修复语法错误
4. 检查信号定义
5. 使用 always @(*) 避免敏感列表问题
6. 添加 default 分支避免锁存器
7. 重新综合
```

### 2. 时序违例

**症状**: WNS < 0，时序不收敛

**常见原因**:
- 逻辑层级过多
- 时钟偏移
- 布线延迟

**恢复步骤**:
```
1. 查看时序报告，定位关键路径
2. 插入流水线
3. 优化逻辑层级
4. 使用寄存器
5. 调整布局布线策略
6. 重新实现
```

### 3. 资源不足

**症状**: LUT/FF/BRAM 使用率过高

**常见原因**:
- 设计规模大
- 资源共享不足
- 未使用 IP Core

**恢复步骤**:
```
1. 查看资源利用率报告
2. 优化代码，减少冗余逻辑
3. 使用 IP Core（如 FIFO、RAM）
4. 资源共享
5. 升级器件
```

### 4. 功耗过高

**症状**: 功耗超过预算

**常见原因**:
- 时钟频率高
- 翻转率高
- 未使用时钟门控

**恢复步骤**:
```
1. 查看功耗报告
2. 降低时钟频率
3. 使用时钟门控
4. 优化逻辑
5. 使用低功耗模式
```

### 5. 仿真不收敛

**症状**: 仿真结果异常，波形不正确

**常见原因**:
- 时序设计问题
- 复位策略不当
- 跨时钟域未同步

**恢复步骤**:
```
1. 检查时序约束
2. 验证复位策略
3. 添加跨时钟域同步
4. 使用 ILA 在线调试
5. 对比 MATLAB 仿真结果
```
